# V27 — Original APBP Antarctic multi-region Penguin synchrony eligibility

Frozen 2026-10-21 after V26. This is an exploratory prospective-in-code test of broad spatial concordance, NOT independent validation of the earlier two-island result or a rescue of closed V6. No Ecology PR189 changes.

Source: SCAR-AntOBIS APBP original Darwin Core Archive v2.3 DOI 10.48361/zftxkr, V2 source-linked original measurement CSV 4750 rows, SHA256 75c98ad9174f6ca8b88ae915adb8bb39de5d279099b45ce1ae7d1b2e25d5ba59. Download the original derived source from GitHub Actions V2 39091772742. This is NOT a new independent source versus V6.

- Target exactly Pygoscelis adeliae, Pygoscelis antarcticus, Pygoscelis papua; source reported NEST counts only with original typed eligibility. Actual abundance magnitudes remain unopened until the data-support gate passes.
- Infer source breeding start season from original December YY or January/February YY+1 dates with YYYY-MM or YYYY-MM-DD source accuracy; allow 1979–2022. Full duplicate original siteID × species × season groups excluded. Source IDs do not equal physical islands.
- Valid adjacent-year count-change pairing: same original site ID/species, years y and y+1, SAME original calendar month and identical nonempty normalized samplingProtocol. No survey gap imputation or no-observation-to-zero conversion. Finite source coordinates in South Polar EPSG3031, grid fixed 250 km. Entire siteID excluded if its original coordinates jump between spatial blocks across available seasons. Original references inspected for continuity statistics, not cherry-picked.
- In one species×start-year stratum, at least 3 distinct site-pairs from a shared 250km block and 3 site pairs from different 250km blocks are necessary for a meaningful near/far comparison. Sites can share field references and are not necessarily distinct physical islands. Freeze the strata before count data.
- MACRO GATE: at least 10 supported species×start-year strata over >=6 distinct years, >=2 Pygoscelis species, >=5 spatial blocks and >=20 distinct original site IDs. If any fails, STOP with source coverage; do not inspect count values or relax thresholds.
- If it passes: observed within-series change sign computed solely from original nonnegative integer nests in two consecutive measured seasons. For each frozen stratum count concordant growth direction among nonzero same-block and different-block site-pairs. Both must have >=3 nonzero-site-pairs or that stratum fails numeric support. Need >=10 eligible numeric strata across >=6 years or STOP. Primary D=unweighted species×year-stratum average of (within same-direction fraction minus between fraction). Directional descriptive support only if D>0 and at least 2/3 individual strata show D>0; report leave-one-year-out range. No p values and no climate, ice, wind, prey, site fidelity, competition, predation, island isolation or coastal rock causal mechanism claimed.
- Source data are a compilation of published surveys; a source site is not an independent penguin population and within-grid pair count is not independent landmasses. The original V6 source overlaps, so results cannot be pooled as independent studies. More source sites alone cannot establish mechanisms. Protect Ecology PR189.
