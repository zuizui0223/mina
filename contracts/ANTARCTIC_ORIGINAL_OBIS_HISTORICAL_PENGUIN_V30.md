## Original publicly downloadable historical source

Eric Woehler (2008), A census of penguin colony counts from the year 1900 to 1996 in the Antarctic Region, FAUNA_PENGUIN_COLONY, first-party IPT/OBIS Darwin Core Archive. Resource https://ipt.obis.org/nonode/resource?r=iasb . Exact version 1.0 original ZIP https://ipt.obis.org/nonode/archive.do?r=iasb&v=1.0 . Original source publicly reports 2,787 records (92 kB archive), last published 2018-10-10, CC BY 4.0. Original penguin colony dataset is not independently observed a second time merely because MAPPPD later republishes some survey events.

## V30 access and original record audit

Retrieve only source-verified version 1.0 IPT ZIP with a 2 MiB transfer bound, max uncompressed 15 MiB, explicit ZIP-slip, CRC, source meta.xml and core DwC occurrence check. Preserve original published ZIP SHA256, original core CSV SHA256, authoritative publisher date, schema field mappings and any count-stage/observation/coordinate-accuracy columns.

Analyze basic source metadata and row counts (publisher expected 2,787): original species/year/locality/site and actual abundance measurement fields, geographical coordinates, original survey event/citation and duplicate source records. Do NOT use original GPS coordinates as verified nests: some source positions derive from locality assignment via the Antarctic Composite Gazetteer. No inferred historical absence from missing presence records.

This gate opens original data records ONLY for descriptive field/source audit, not a new biological effect model. If original core contains only occurrence presence and no direct abundance metric, future count-island macro models must stop. If original survey citations overlap MAPPPD or pre-existing AADC cohorts, report genealogy rather than count as independent species/island replication. Any later physical island or exposed-rock topology analyses must hold source geographic precision and original count-stage uncertainty constant.

## Biogeographical decision

A genuine original-data cross-system Antarctic theory would contrast P (physical island landmass), F (exposed nesting-substrate network) and T (seasonal fast-ice continuity) against annual breeding occupancy, growth or redistribution using independently surveyed real absence and count grain. Historical presence-only records cannot estimate reoccupation, extinction or true island effects. This V30 tests feasibility rather than promoting a published authors' descriptive trend into an independent discovery.
