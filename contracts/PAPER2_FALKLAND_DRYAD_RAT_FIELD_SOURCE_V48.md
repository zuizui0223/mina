## Frozen source-only process and gates
1. GET exactly DOI dataset metadata via first-party `datadryad.org` HTTPS with a bounded response/redirect host allowlist and 15s connect / 45s read timeout. Verify publicly **Published** (not embargo/private), original identifier, licence or reuse terms, and current version ID. Do not treat meta description alone as data.
2. GET current public version file listing from first-party API for that DOI; list filename, official file ID, size, MIME and integrity digests. Deny download if missing original source record or licence terms, >10 MB per file or >20 MB aggregate. No discovery of other paper files to rescue the sample size.
3. Report whether source field files actually contain original distinct **island name or island ID and survey/rat status data**. A paper's aggregate 85/108/37 ratios in the abstract are not a machine-readable island crosswalk and cannot be joined using source centroid nearest points.
4. If files are original, openly licensed, tabular and bounded, inspect source column HEADER/shape and nonpersonal categorical enums only (do not emit raw original site names or precise bird/mammal locations, data-publisher surveyor identities, lat/lon). **NO V47 original bird result reopened in this first external-source step**.
5. Match source island name to V47 66 original FIG locations only in a subsequent frozen source-join module; no fuzzy matching, only strict original name/Island ID crosswalk and survey-year alignment 2007–2013; do not infer island ID from 230 row order. Do not automatically mark missing Tabak island as mammal absent.
6. Source original documented rat categories are status *at the source survey or eradication date*. "Historically rat-free" or "no evidence" is not proof of perfect detection sensitivity, and eradicated is a distinct status with its own date and reinvasion uncertainty. If no field inspection/effort at island/time, code `UNVERIFIED` not negative. A mainland status cannot be projected onto another offshore island.
7. Only when original statuses genuinely link to ≥10 rat-source-positive AND ≥10 verified field-surveyed historical rat-negative **among the actual 66 V47 same-year breeding islands**, with ≥2 original source area groups and valid date overlap, may a subsequent model be considered; compare field-vs-recording bias and same-survey prey/P/A observational denominators first. V47 G3 strict same-date joint effort remains independent and currently not verified.
8. If not recoverable/overlapping, the valid outcome is source STOP with exact reason. Keep V47 69 positive co-breeding opportunity intact. Do not make it a test of predator effects, flyability, dispersal, anti-rat island status or the Antarctic natural experiment by inventing statuses.

## Scientific interpretation & conservation source
Original Tabak 2015 rat-island passerine results, including rat eradication history and passerine changes, were already published. At most the original rat surveillance covariate could strengthen OUR distinct within-Falklands seabird guild comparison. Source rat contrast is observational, not natural randomized exclusion. Original high-res Antarctic BAS nests (122,139) are all penguins; they cannot supply a flying guild counterfactual. In Paper2 introduce independent coastal route mapping only after documented suitable unoccupied breeding habitat/shore access. Frozen Ecology Paper1 #189 is untouched.
