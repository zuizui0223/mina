# Antarctic candidate-breeding-site network — AADC original geometry, v1

**Independent geographical metric lane, created after V1 strict AADC×SCAR biological sample STOP on 2026-10-25. This is NOT a threshold rescue of that failed physical-rock containment test. Do not change the STOP or claim evidence of an island barrier.**

## Research target

Physical land polygons, true available breeding patches, and publisher-defined geographic *potential breeding sites* are different spatial objects. This lane uses only the original AADC 2025 geographic-site reference (7,785 distinct sites) to measure potential local breeding-site choice networks without requiring unreliable containment in a different GIS map edition. All earlier biological P/A results remain previously exposed; any subsequent species association from this cohort is exploratory.

## Source-only geometrical descriptors

Original geographic site IDs, original decimal lat/lon, original source island/continent label, original 2021-frame inclusion, original area *if units are validated*. The first GIS stage uses no P/A, count, phenology or search response.

WGS84 → Antarctic polar EPSG:3031 for the same site-centered candidate-point geometry at all sites. Report these distances as approximate local projected Euclidean separation of author-defined potential-site reference points, **not ecological dispersal distances, water-barrier crossings or verified nest locations**.

Primary unchanged target: all 7,785 original 2025 potential-site IDs. Source-era sensitivity: 4,862 IDs found in both 2021 and 2025 versions. No target labels/locations are modified.

For each source geographical site, compute:
- nearest other potential-site centroid distance;
- nearest potential site within the same source-labeled geographic class (island vs continent);
- nearest site across those *author source classes* (not physical same-island vs other-island);
- counts of *other* candidate-site centroids within **2, 10 and 50 km**; the three radii are fixed from a local-intermediate-regional nesting-scale hierarchy and analyzed descriptively as three different scales, not cherry-picked post-species outcomes.

Missing neighbor distances remain missing, not 0. Original source site classes indicate whether that *site* was labeled island or continent, **not that two 'island' points belong to the same physical island**. Consequently same-class distances are not within-island distances; no degree of island or sea matrix isolation is inferred at this stage.

Report complete spatial distributions and stability of geometry variables between the 2021 shared and 2025 extended source site frames. Treat expanded source-site coverage as a survey-frame change, not biological colonization.

## Ecological interpretation and stopping rules

This generates one new macro spatial predictor matrix that can later enter original survey-effort and geography-adjusted models, but it is observational site density (survey-map geometry) and can encode biased mapping/field sampling. Biological claims require source-P/A-ready site support, full spatial heldout and survey effort controls. Separate penguin and flying seabird programmes cannot be treated as synchronous field observations. Prefer prospective independent repeated breeding-site surveys for confirmatory testing.

No tuning of the strict physical SCAR test to recover this larger AADC cohort. The 6 vs 11 site strict geographic support STOP stays frozen as `results/AADC_SCAR_STRICT_SURVEY_SUPPORT_V1.json`.

Official original geographic source SHA256 receipts are those independently verified in `results/AADC_GEOGRAPHY_SITE_EDITIONS_V1.json`. No animal outcomes are permitted inside the geographical network builder.
