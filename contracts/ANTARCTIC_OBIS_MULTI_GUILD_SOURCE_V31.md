## Strict biological fit gate

Only use first-party source group/year if the source actually defines count stage (nests or breeding pairs), original numeric integer counts, survey year, adequate geographic/landmatch identity and independent survey effort. If these data are **only count magnitude of mixed colony estimates**, then STOP species-level count response modelling; available output is a source-era archaeological database completeness and flight-capable vs flightless taxonomic inventory.

No canonical physical island can be created from locality text alone. At a minimum de-duplicate old event year/species/site under original reference and later MAPPPD source citation. Original 2018 historical archive and latest MAPPPD are not independent confirmations until true observer/citation lineage checked. Asymmetry in which taxa/locations were reported cannot be read as extinction or re-colonisation without explicit surveyed zeros. A genuine novel polar island result ultimately requires independent annual field-sampled occupancy/counts, ice/snow availability and source island identities.
