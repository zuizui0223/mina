## Georeferencing QC and screening outputs (to compute for the first time)

- Rebuild unique APBP public source `locationID` coordinate pairs from authentic publisher Event core, with fixed WGS84 `decimalLongitude/decimalLatitude` and source `coordinateUncertaintyInMeters`. Sites where original Event coordinates disagree by >1 km between surveys are flagged `HOLD_COORDINATE_DRIFT`; do not silently assign a single polygon from a cherry-picked year.
- Project all to ADD EPSG:3031 with pyproj `always_xy`. Verify original shapefile .prj objectively equals EPSG:3031, numeric finite polygon geometries, `surface` label and original source SHA256.
- For each unique site, match to an actual standalone land polygon or the single contiguous Antarctic mainland polygon: (a) exact point inside one land polygon; (b) if not, unique nearest polygon within **250 m**; (c) ambiguous overlaps or >250m unmatched, **NOT ASSIGNED**. The largest land-polygon feature is only a *provisional continental candidate*; the other disjoint features are *provisional islands* (not verified until high-resolution confirmation), without using site names or APBP `islandGroup` as classification. Need to guard large isolated islands and Antarctic ice shelf land-vs-ice labels.
- Compute only the **total mapped exposed-rock polygon intersection area within an independent 2,000 m radius from the point**, and a prespecified 500 m radius sensitivity. Use an exact union of intersecting rock polygons, not double-summing overlapped mapped rock parts. Report original island land-polygon area and site coordinate uncertainty separately. This describes *available mapped rock in proximity*, **not verified accessible nesting capacity, annual increase in habitat, or penguin nest habitat quality**.
- Do not backfill unmatched coastline for emperor sea-ice colonies, nor assign `rock=0` to unmapped small islands. Either geometry/group missing yields NA/HOLD. The 2026 coastline and 2025 rock layer have different snapshot dates and do not estimate temporal shoreline change.
- Outcome: a versioned `site × location × provisional land-polygon` derived CSV, original archive fingerprints, counts matched/unmatched, rock coverage summaries and coordinate-drifts count. **No breeding trend or regression, no p-value, no relationship between nest count and rock area calculated.**
- Combined stage3 with original APBP nest data requires joining by exact original locationID, retaining site/species/year/method N1–N5 values and original survey references. Only after this, independent offshore environmental time series can be matched; only then may a signed ecological effect be tested.

## Stop rules

If either GIS ZIP returns a publisher HTML page instead of shapefile archive, if a CRS is missing or not EPSG3031, if land category cannot be identified, or if original polygon geometry is invalid on features near target sites, emit a source-geometry scientific HOLD. Synthetic tests must prove that an omitted micro-islet is **unmatched** rather than mainland and that ice shelf polygons are excluded. Do not fabricate lat/long for any site. Result success at this stage is **linkability**, not H1 support.
