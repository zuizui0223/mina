# V28 independent primary Antarctic (not SSI) nest GIS source campaign

**2026-10-26, new first-party source inventory only; no original animal
observations, density, nest point coordinates, counts or occupation
states opened.** Prior South Sandwich V21/V22/V27 species clustering
and nonportable terrain-prediction results are exploratory and frozen;
neither a new source nor a field programme can be selected because it
would reverse an inconvenient effect.

## Source-first independent polar mainland / island records

AADC official original public source catalog / EDS API:
1. Original Windmill Islands 1998/99 multi-bird guild GIS,
   metadata ID **windmill_flyingbirds_gis160**: mapped polygon areas
   for Adélie penguin colonies and flying bird colonies, and point
   nest location records for source flying birds, from Frazier
   Islands, Ardery Island and Casey Station area. Some historic
   source locations were digitised from sketches, others from
   differentially corrected GPS. **Do not assume all source
   nest points are equal precision or all negative patches surveyed.**
2. Original Bechervaise Island Adélie nest points,
   metadata ID **bech_nest_locations**, DOI
   **10.4225/15/595350e32bffc**. Original 2000–2002 total station
   and marker-based nest mapping in K/L/Q colony groups. A source
   0.05-m GPS/total station accuracy stated for most K/Q,
   lower precision for some earlier sites. One Antarctic island,
   one taxon; important independent microspatial calibration but
   **not** new comparable island richness or species-pair replicate.
3. Original 1972–1974 and 2017/18 Cape Petrel nesting
   ranges among Vestfold Islands, metadata ID
   **AAS_4518_Cape_Petrel_population_estimates_VestfoldIslands**.
   Source years, surveyed colony footprints and nesting-detected
   boundaries must be matched. Two periods alone do not establish
   continuous demographic turnover or spontaneous colonisation.
4. Original Macquarie Island albatross/giant petrel
   (2012–2013) point/colony GIS, metadata ID
   **AAS_4112_Nest_Colony_Locations**, DOI
   **10.26179/5b3c4244b0c53**.
   *Sub-Antarctic flying-bird analogue, NOT Antarctic mainland
   biological replication*.

## Fixed source eligibility rules

Read current publisher original /eds/api/dataset public registry. Match
ONLY exact case-folded source metadata IDs from four frozen records;
a missing original dataset in the modern EDS registry remains
**SOURCE_INDEX_HOLD**, never zero original nests nor a fabricated
modern ID or a private dataset guess.

For each official verified original dataset UUID, request ONLY
its original object metadata index, listing original path, extension,
declared size, parent source reference and authoritative index SHA256.
File object names/shapes are source discovery, not observation values.
Do not download original raw geographic shapefiles in this gate,
or infer species/nest stage from an uninspected column name.

Rank source readiness by spatial original geometry (point+polygon)
and original survey precision documented in metadata. Original
EDSpublisher availability and original licensing must be checked
before any subsequent source point analyses.

## Biological gate before cross-system modelling

The transferable null is that physical landmass connectivity P,
functional exposed/habitat substrate F and dynamic fast-ice T
control spatial nest occupancy across independent physical islands
and original years, after source observation effort.

A source with one present-only nest GIS and no independently
mapped surveyed absence cannot test occupancy probability,
recolonisation or resource/habitat suitability. A source with
several highly precise nest points on the same island cannot
be inflated into many island replicates. Do not merge original
1998/99 Antarctic birds with 2019/20 South Sandwich observed
bird counts as if they were contemporaneous or nested surveys.

Potential original contribution: independently constructed source
GIS macro repository integrating real breeding patch geometry
at multiple polar islands with explicit source precision, time,
observed-absent vs never surveyed, and source-known substrate
continuity. No causal new island law is expected from metadata
registration itself.
