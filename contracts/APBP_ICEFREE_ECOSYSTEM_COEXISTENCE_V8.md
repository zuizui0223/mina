# V8 — Antarctic terrestrial ecosystem mosaic × sympatric penguin nest balance

**Date 2026-10-19, distinct from closed negative marine×land V6.** This is a new limited, **exploratory** ecological comparison motivated by missing terrestrial niche information, *not* an adjustment of V6 until a coefficient turns positive. Before this contract, the **outcome support only** was checked: pinned APBP source includes 350 original simultaneous multiple-Pygoscelis nest-census Events at 62 source locationIDs, 62 with nontrivial within-event two-plus Pygoscelis taxa; 51 original sites provisionally island, 6 mainland, 5 geounmatched in original high-res ADD map. Exact model-related ecosystems-vs-nest abundance correlations have NOT yet been computed.

## Why a distinctly Antarctic breeding question

*Within established known colonial penguin rookeries, does a mosaic of terrestrial ice-free habitat types near a breeding locality predict more equitable breeding effort between co-reported Pygoscelis species, once geographic position, original census magnitude and species-pair identity are accounted for?* Competitive exclusion would predict a stronger dominant-species allocation; possible fine-scale niche partitioning predicts a more even observed nest balance when different ice-free terrestrial environments are available. This asks about ecological sorting **conditional on the original confirmed co-census**, not inferred absence, immigration, individual competition, site take-over or new colonization.

**Known conceptual prior art:** site habitat heterogeneity and species coexistence are generic established ecology. It will count as genuinely new to Antarctic island ecology ONLY if a taxon-specific spatially transferable relationship survives strong holdouts, measurement/position uncertainty controls and independent validation. Discovery is not presupposed.

## Strict data and independence

- Source species and nest counts: original SCAR APBP v2.3 (DOI 10.48361/zftxkr), publisher SHA256 `afa947f39d9ad7382266d5be64c70f9fe4e84ffb6e2838c1369e043caae09abf`, original Event→Occurrence→eMoF observation join and explicit nest measurements from V2 derived CSV SHA256 `75c98ad9174f6ca8b88ae915adb8bb39de5d279099b45ce1ae7d1b2e25d5ba59`. One original multi-Pygoscelis same Event core per paired measurement; do not join across independent survey dates/years, infer missing-species absence or reuse old revised MAPPPD as independent bird observations.
- **Genuine external terrestrial ecology input:** Antarctic Ecosystem Inventory (Tóth et al. 2025, DOI 10.5281/zenodo.11629115; source article DOI 10.1038/s41597-025-04424-y), 100 m ice-free ecosystems GeoTIFF `AntarcticaEcosystemInventory_IceFreeLands_v1_int.tif` (published MD5 `cde880d73f7f18b44aecf5690aa2dc92`) and matching VAT DBF (published MD5 `fa5363b1c0d882b4343e239d03dc2ba4`). Direct official Zenodo download; never derive maps from penguin count data. **Only Tier 1 (nine abiotic Major Environment types) is used as habitat predictor; exclude Tier 2 biotic fitted suitability and Tier 3 geographic region labels and any explicit penguin rookery overlays.** This avoids direct response-label leakage through ecology-map biotic classes. Raster is *static*, not an observed annual snow-free duration, causal glacial retreat or surveyed availability of empty nests.
- Original high-res 2026 ADD coast positional classification V4 is context only; location uncertainty missing for 22/62 multi-species sites and median known ~917 m. Because original source points often differ from true subcolony spatial extents, sample habitat in **a fixed 5-km circular neighborhood** of each original site coordinate, with 2-km radius a *predeclared* sensitivity not an alternative posthoc preferred scale. No microhabitat/cause claims.
- Only **actual simultaneously surveyed nest counts** among the three Pygoscelis spp, original exact shared `original_event_core_id`, and `eligibility == ELIGIBLE_NEST_RECORD_ONLY`. Compare **all pairwise combinations of measured species** within an Event, excluding a pair only when the total (N_1+N_2=0). A species absent from an Event is NOT counted as 0. Both measured positive OR one true measured zero is an actual observed balance. For each pair define **balance = 2 min(N1,N2)/(N1+N2)**, 0 to 1.
- To prevent temporal pseudoreplication: before fitting, aggregate observations to **one source site × unordered species pair**, taking the median event balance and mean log1p source pair total count; original median precision grade and count of original distinct Events retained. This yields **at most 3 species-pair rows per original site** and all of a site's rows are always in the same CV fold. No selection of a favorable year, count, source site, or source grade.
- Original site point has no valid population when habitat data unavailable. Require **at least 30 valid ice-free 100m raster pixels** within each 5km circle (and archive valid fraction of circle), original 100m projected CRS and exact Zenodo MD5. The raster's NODATA is **unknown/ice/ocean not a mapped ecosystem pixel**, not a measured negative habitat site. Preserve all sites that fail coverage as `HOLD_NO_MAPPED_ICE_FREE_HABITAT` without creating zero habitat entropy.
- Main habitat heterogeneity predictor is **Shannon entropy of Tier1 labels divided by log(9)** across valid ice-free pixels in 5km circle. Compare against recorded **ice-free mapped fraction of all raster-grid centers within 5km** to distinguish diversity from amount. Median tier1 class and number of distinct classes provided descriptively. Caveat: ecosystem Tier1 inputs include mapped abiotic variables, so correspondence to penguin source lat/lon and coastal exposure is observational, not independent field sampling of nests.
- Sensitivity: exclude source sites with known coordinateUncertainty >1km; because precision is missing at >1/3 sites this is a *robustness subset*, not a random or high-confidence sample. Evaluate 2km habitat entropy ONLY as originally predeclared sensitivity, report both results even if signs differ.

## Frozen nested predictive analysis before habitat raster pixels or outcome coupling inspected

- B0 (null): pair-level median balance predicted from species pair indicators, latitude, `sin(lon)`, `cos(lon)`, log1p median source total nests, median source measurementAccuracy (1–5), log1p number of original co-census Events. These control known variability and report biases; do not claim all census detection uncertainty is corrected.
- B1 (ecosystem mosaic): B0 plus normalized **5km Tier1 Shannon entropy** and **5km ice-free mapped fraction**, as additive predictors. No post-result radii, habitat rankings, species recoding, extra interactions or cherry-picked spatial subdivisions.
- Fixed ridge penalty `alpha=10`, z-scale continuous features within training folds only, intercept unpenalized; binary species-pair indicators leave valid original site codes. Primary generalization statistic `Δ = equal-250km-block MSE(B0)-MSE(B1)`, leave-one-original-coarse-block-out; also give *site-weighted* heldout error and per-block gain and source site counts.
- Minimum support for an ecological descriptive mosaic association: `Δ > 0`, at least **2/3 of qualifying spatial blocks with >=3 distinct original source sites** improve and `entropy coefficient sign` stable when **largest block** excluded, and known-source-coordinate-uncertainty <=1km subset gives same sign. Otherwise classify `NOT_SUPPORTED_OR_UNIDENTIFIABLE`. An effect cannot be claimed island-specific with only **6 continental** multi-species sites. Never report confirmatory p-values, causal trait partitioning, nesting substrate competition, colonization or protected-area recommendations.
- If eligible source site-pairs <40 or spatial blocks with >=3 sites <4 after valid raster coverage, **STOP modeling** and report only cohort support.
- If positive, may only state that **within already co-recorded established rookeries**, terrestrial abiotic mosaic predicts independent source nest-balance measurements outside sampled regions; still not the new causal island biogeography law. If negative, preserve; do not re-tune V6 or V8 to rescue.
