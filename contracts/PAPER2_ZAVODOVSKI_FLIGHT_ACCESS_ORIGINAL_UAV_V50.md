## Natural comparison and precise directional prediction

**One actual physical island, one 14 Dec 2023 same-UAV date, three seabird taxa:**
- `giant_petrel_colony_boundaries_2023` = Southern giant petrel flying seabird colony POLYGONS (NOT individual point-nests).
- `chinstrap_colony_boundaries_2023` = flightless chinstrap penguin colony POLYGONS.
- `macaroni_colony_boundaries_2023` = flightless macaroni penguin colony POLYGONS. One *genuinely original zero-vertex placeholder* was already independently documented, may be explicitly counted/skipped, never spatially filled.
- `zavodovski_coastline_2023` = BAS MAGIC polygon for the island shoreline. This is a single published source island, not mainland/group proximity proxy.
- `area_outwith_drone_survey_2023` = original publisher outside-UAV-survey polygon; exclude it from any species comparison. Do NOT substitute 2025 chinstrap coverage, 2011/2016 satellite cloud infills or 2020/22 composites.

These exact five data layer names and same original date were independently listed in official `layer_descriptions.csv` 28 rows (BAS original DOI `10.5285/7220dc6b-2f52-4160-a6c0-e57c50963308`, OGLv3, actual data source 2026). The full original BAS 2023 UAV data producer states >90% coverage of known penguin occupied area but not complete absence surveys everywhere; never generalize unoccupied land as true absence of birds, giant petrels or penguins. Colony polygons are **breeding area footprints**, not numbers of nests or adult movement tracks.

**Directional V50 hypothesis** (before reading *new petrel* polygon values): area-weighted median shortest horizontal distance from original coastline of mapped flying **giant petrel** colony habitat is **greater** than for pooled mapped flightless chinstrap+macaroni penguin colony footprints, on the same surveyed Zavodovski landscape (D=flying−flightless >0). Predicts accessible-from-air breeding footprint can sit further inland than penguin colonies requiring a shore-to-nest terrestrial approach. This is an observational candidate mechanism, not proof that distance is the actual walked path or mammalian predator attack risk.

### Source and sample gates
1. Retrieve **only** five source 2023 shapefile layers (each `.shp`, `.shx`, `.dbf`, `.prj`, `.cpg`) from the original public BAS RAMADDA 2023 `drone-derived_data` folder using authenticated source manifest entries and original DOI prefix. Verify first-party source domain, original file extension, signatures and EPSG:32726; SHA256 all originals and original source 28-row data dictionary. No raw animal coordinates or original site IDs published in Git results.
2. Fix EPSG:32726, original mapped coastline as **land polygon**, original `outside_drone_survey` as unsurveyed. Source covered land = coastline polygon excluding the unsurveyed polygon. Original penguin and petrel polygons are clipped to this same mapped survey region. All three taxon polygons must be source-original geometrically valid; only an original zero-vertex macaroni placeholder documented by PR #196 may be excluded (exactly ONE).
3. Measure original polygon counts and **mapped occupied polygon areas** for petrel, chinstrap and macaroni; separately the overlap of taxon polygons after clipping (source simultaneous mixed patches). Never attribute an overlapping area solely to either guild; omit overlap/mixed areas from D and report its area. Never label outside occupied polygon as true surveyed non-breeding habitat.
4. Fixed deterministic area-sampling grid in UTM EPSG32726, 20m cell centres aligned to origin `0,0` in projected coordinates; two secondary 10m and 40m grid-centre checks. Only retain points within source coastline AND outside source unsurveyed area, and inside **exactly one guild** of nonoverlap colony footprints. Directly compute minimum projected Euclidean horizontal distance to *outside coastline* (outer ring), not a coastline entry/landscape walking path. No slope weighting, cliff passability threshold, arbitrary boulder access or habitat availability inferred. Pixel-scale centroid approximations openly stated.
5. Sample support threshold before source effect: nonoverlap flying giant petrel ≥**20** 20m grid centres and pooled penguins ≥**100** 20m grid centres, ≥1 actual nonempty petrel and both original penguin polygons. This is not 20/100 biological island replicates; grid samples approximate mapped **area** on ONE island. If gate fails, report original counts and STOP directional D (do not loosen thresholds).
6. On gate pass, record area-weighted median coastline horizontal distance by guild, D=flying minus pooled flightless, plus original species-level medians and 10m/40m sensitivity **without selecting sign**. NO inferential p value based on pseudoreplicate 20m cells; no causal flightlessness attribution (species identity, nest physiology, microhabitat, predator avian interactions and source mapping differ).
7. **H_F physical coast-path test not yet identified**: nearest geometric coastline distance is a lower bound to landscape travel; actual repeated shore-to-nest penguin walkability requires independent seasonally contemporaneous DEM, slope/passability, and shore-entry GPS evidence, and flying seabird flight access is not a measured counterfactual. **H_M mammal effect not tested** because Zavodovski has no published introduced mammal predator treatment variation; independent regional report describes South Sandwich Islands as free of introduced species, NOT free of avian/marine predators.
8. No extrapolation to 122,139 BAS Hart penguin nest points on Saunders/Bellingshausen/Thule, which are different 2019/20 campaigns on other islands, no flying bird source among those original ten nest CSVs. No use of UK Stanbury source label SDMs, no 66 FIBD named locations as physical islands.

## What a positive result would mean

Only that, **within one same-date original UAV mapped island landscape**, flying giant petrel breeding-polygon area can occur farther from waterline than penguin colony polygons. If D≤0, the narrow distance prediction fails; the same island could instead be organized by species habitat, predator avian access or other local conditions. Neither case shows a general island biogeographic physical island refuge/flight interaction, since n independent islands=1. Integrate as constrained mechanism demonstration alongside Falklands 66 named-source co-breeding sites and new multi-island data, not a stand-alone new paper.
