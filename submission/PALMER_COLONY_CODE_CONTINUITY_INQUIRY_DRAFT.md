# Palmer colony-code continuity inquiry draft

**Suggested recipients:** dataset scientific contributor (William Fraser, contact listed in the official ERDDAP metadata) and/or the Palmer LTER data publisher/information manager (John Kerfoot, contact listed in the dataset metadata).

**Subject:** Clarification on long-term Palmer Adélie colony-code continuity

Dear Dr. Fraser / Palmer LTER data team,

I am preparing a reanalysis of the public Palmer LTER Adélie breeding-pair census (DOI 10.6073/pasta/89dd52217ca37e3a72a67f7a9bc3c82e). The analysis asks whether, during population decline, breeding pairs became disproportionately concentrated among fewer monitored colony components rather than declining in fixed proportion across components.

For the primary Palmer analysis I restrict attention to Cormorant, Humble and Litchfield islands, where the published `colony_code` roster is unchanged over the eligible census interval. Before submission, I would like to verify one methodological point about the longitudinal meaning of those codes.

Could you please clarify whether a given `colony_code` on an island was intended to refer to the same mapped physical breeding colony/group through the 1991–2017 census series? In particular:

1. Were colony boundaries or code assignments ever redrawn, split, merged, or reassigned while retaining the same code?
2. If boundaries changed, is there a map, crosswalk, field protocol, or change log that documents those changes?
3. Is it appropriate to interpret a time series for a fixed `colony_code` as the abundance history of one persistent census colony, or should the code be treated only as a nominal monitoring unit whose physical boundary may have changed?

I am not asking for unpublished population results; the question is only about the semantics and continuity of the monitoring units. In the manuscript I currently describe the Palmer units conservatively as nominal monitored census colonies and avoid equating them with the mapped GIS subcolony polygons used in later spatial studies.

Any clarification or pointer to the relevant documentation would be extremely helpful. I would, of course, cite the public dataset and any documentation you recommend.

Thank you very much for maintaining and making this long-term data set available.
