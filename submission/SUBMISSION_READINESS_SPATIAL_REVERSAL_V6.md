## Current mechanistic spine

    temporary breeding-state/access shock
        -> prior adults + breeding network remain available
        -> old spatial template can be re-expressed

    demographic turnover / attrition
        -> local demographic multipliers differ
        -> relative composition can be rewritten

    breeding-capacity change
        -> settlement opportunities change
        -> redistribution can move to a different spatial level

Evidence roles:

- Ross 1999-2001-2002: primary temporary-shock case;
- Palmer + Signy: persistent attrition cases;
- Beaufort: capacity-change case;
- Bird + Heard + Emperor: boundary evidence against a simple aggregate-direction rule, not forced mechanism classes.

## Important limitation

Do not invent a common score merely to obtain a class comparison.
