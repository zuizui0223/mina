**Interpretation rule.** Rows are not exchangeable estimates of one common effect. The table deliberately preserves different estimands because the biological processes create different observational designs.

**Claim ceiling.** The table supports distinct process-anchored spatial signatures in the available cases and falsifies a universal abundance-direction rule. It does not estimate a three-class effect or prospectively confirm a general process-dependent spatial-memory law.
