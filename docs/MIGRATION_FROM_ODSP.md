# Migration from ODSP

The Palmer island-ecology follow-up was first prototyped in
`zuizui0223/odsp` on branch `ecology/penguin-island-reassembly-v1`
(draft PR #186).

`mina` is now the development repository for the biological project.

ODSP retains:

- the frozen N2 failure-mode experiment;
- the frozen Palmer Penguins Stage-2 receipt;
- the methodological interpretation of pooled versus species-conditioned
  predictive gain.

mina owns:

- the Adélie three-island biological reanalysis;
- the island/year reassembly tests;
- APBP/MAPPPD long-term abundance harmonization;
- community-weighted trait and turnover analyses;
- later sea-ice / snow / phenology mechanism extensions.

No ODSP frozen receipt should be edited to accommodate results generated here.
