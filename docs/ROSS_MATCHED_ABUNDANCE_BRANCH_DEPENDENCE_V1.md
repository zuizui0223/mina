# Ross Island matched-abundance branch-dependence audit v1

**Status:** post-result exploratory diagnostic. This is not a confirmatory test of hysteresis.

## Question

At approximately the same total occupied breeding abundance, is Ross Island spatial composition the same on the pre-shock decline branch and the post-shock rebound branch?

If spatial state were determined only by current total breeding abundance N, then matched-N years should have similar E.

If history/configuration matters, similar N can occur at different E.

## Mechanical support rule

Use the frozen decline years:

    1985-1999

and frozen recovery years:

    2001, 2002, 2003, 2004, 2005, 2006, 2007, 2009, 2010, 2011, 2012.

First define the observed N range in the decline phase:

    min N = 145,268
    max N = 242,644.

Recovery years are eligible only if their N lies inside this decline-phase support range.

This leaves exactly two recovery years:

    2002: N = 203,996
    2004: N = 221,301.

For each eligible recovery year, select the decline year minimizing absolute difference in log N.

No pair is chosen by E.

## Pair 1 — 1997 decline vs 2002 rebound

Decline branch, 1997:

    N = 204,837
    E3 = 1.6261
    E6 = 2.1706.

Recovery branch, 2002:

    N = 203,996
    E3 = 1.5074
    E6 = 1.8190.

Differences:

    N: -0.41%
    E3: -7.30%
    E6: -16.20%.

Thus nearly identical total breeding abundance occurred with substantially greater concentration on the rebound branch.

## Pair 2 — 1985 decline vs 2004 rebound

Decline branch, 1985:

    N = 224,414
    E3 = 1.6252
    E6 = 2.2902.

Recovery branch, 2004:

    N = 221,301
    E3 = 1.4130
    E6 = 1.8652.

Differences:

    N: -1.39%
    E3: -13.06%
    E6: -18.56%.

Again, similar total breeding abundance occurs with lower spatial redundancy on the rebound branch.

## Interpretation

The observed relationship is:

> current total breeding abundance does not uniquely determine spatial breeding configuration.

The same order of total abundance is compatible with different allocations among Royds, Bird and Crozier depending on whether the system is observed before or after the mega-iceberg disturbance.

This is a **branch-dependence signature**.

## Why this is consistent with hysteresis

Prior Adélie work already demonstrates spatial hysteresis/frozen-herd dynamics at subcolony scale under fragmentation, edge predation and nest-site fidelity.

If such configuration memory contributes at colony/network scale, then the same N can map to different spatial states depending on history.

The matched-abundance result has exactly that geometry.

## Why this does not prove hysteresis

The two branches also differ in external environmental state.

The rebound years occur during/after the mega-iceberg era, with different sea-ice access, breeding participation, food conditions and colony-specific demographic rates.

Therefore:

    matched N + different E

does not identify whether the difference is caused by:
- endogenous spatial memory;
- external environment;
- both.

No causal hysteresis label is assigned.

## Prospective discriminating prediction

A future test must compare breeding nodes at matched:

- current breeding abundance;
- contemporaneous environmental conditions;
- usable nesting capacity;

while varying prior fragmentation/configuration.

If prior configuration predicts subsequent reproductive success or recovery after those controls, that would support configuration-mediated hysteresis.

## Manuscript role

Use this as a Discussion-level signature that motivates a prospective test.

Do not present it as a primary Results pillar or as proof that Ross Island has a colony-scale Allee threshold.
