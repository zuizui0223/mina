# Torgersen source gate v1

Candidate public sources, inspected only for machine-readable support:

1. Cimino et al. 2025 Landscape Ecology, DOI 10.1007/s10980-025-02088-y.
   - Supplementary file1 is a DOCX (~15.9 MB).
   - Published paper states historic 1998/99 perimeters were digitized from Patterson et al. (2003), 2020 perimeters from drone imagery, and 2022 perimeters by walked GPS.
2. Duke Research Data Repository, DOI 10.7924/r4sf2xs2w.
   - 30 files / 648 GB.
   - raw imagery, orthomosaics, DSMs, flight plans and ground-control points; SHP format is present in the archive.
3. Palmer LTER census.
   - annual sub-colony counts exist but a public exact census-code ↔ published GIS-polygon bridge is already known to be unresolved.

Stage A asks only whether sources 1–2 expose an exact historic-subcolony identity/geometry/extinction bridge. If not, dynamic cascade inference stops.
