# Ross recovery temporal robustness audit v2

**Status:** post-result robustness audit. Supersedes V1. The frozen V2 prediction and period remain unchanged.

## Frozen decision

The pre-effect contract defined recovery as 2001-2012 and predicted increasing three-colony E.

Observed frozen endpoints:

    N: 94,798 -> 351,119
    E3: 1.7286 -> 1.5428
    E6: 2.2919 -> 1.9702.

Therefore the frozen recovery-deconcentration prediction fails.

That decision is unchanged.

## Biological correction

The 2001 start is an externally documented mega-iceberg disturbance trough.

Published work reports that in the initial B-15A / C-16 grounding season many adults failed or abandoned breeding attempts early.

The aerial series measures occupied nesting territories / breeding abundance near incubation rather than total adult population size.

Thus the 2001 -> 2002 +115% change is a **breeding-abundance rebound**, potentially combining:
- renewed breeding participation;
- survival;
- recruitment;
- immigration/emigration;
- colony-specific environmental response.

It is not interpretable as one-year adult population multiplication.

## Three-stage decomposition

### Shock: 1999 -> 2001

    N -54.3%
    E3 +7.4%
    E6 +11.5%
    all six components decline.

Interpretation:

    shock-induced equalization.

### Immediate rebound: 2001 -> 2002

    N +115.2%
    E3 -12.8%
    E6 -20.6%
    all six components increase.

Interpretation:

    asymmetric breeding rebound concentrated at Crozier.

### Longer recovery: 2002 -> 2012

    N +72.1%
    E3 +2.3%
    E6 +8.3%
    all six components increase.

Interpretation:

    modest spatial re-expansion / stabilization.

## Pre-shock comparison

1999 -> 2012:

    N +69.3%
    E3 -4.1%
    E6 -4.2%.

Royds remains below its 1999 breeding count, whereas Bird and Crozier exceed theirs.

Therefore the strongest long-term statement is not "recovery eroded redundancy."

It is:

> breeding abundance recovered well beyond the pre-shock total, but the spatial composition did not return exactly to the pre-shock state.

## Temporal regression

Across the frozen 2001-2012 years:

    log(E3) slope = -0.00549/year
    descriptive p = 0.246

    log(E6) slope = -0.00589/year
    descriptive p = 0.358.

Starting descriptively at 2002:

    E3 1.5074 -> 1.5428 (+2.3%)
    E6 1.8190 -> 1.9702 (+8.3%).

Thus there is no evidence for a smooth phase-long decline in E.

## Branch dependence

At nearly identical total breeding abundance:

    decline 1997:
    N = 204,837
    E3 = 1.626

    rebound 2002:
    N = 203,996
    E3 = 1.507.

And:

    decline 1985:
    N = 224,414
    E3 = 1.625

    recovery 2004:
    N = 221,301
    E3 = 1.413.

This shows that E is not a single-valued function of N in the observed trajectory.

Call this a **branch-dependence signature**.

Do not call it proof of endogenous hysteresis because the environmental states differ.

## Correct wording

Prefer:

> The iceberg disturbance temporarily equalized Ross Island breeding abundance among colonies. The immediate breeding rebound was disproportionately concentrated at Cape Crozier, after which redundancy partially re-expanded but the long-term composition remained modestly different from the pre-shock state.

Avoid:

- "the adult population doubled from 2001 to 2002";
- "spatial redundancy steadily eroded during recovery";
- "recovery generally concentrates";
- "the observed loop proves an Allee-driven hysteresis mechanism."
