# One-paper hypothesis strategy v2 — spatial recovery hysteresis

**Date:** 2026-10-05  
**Status:** prospective strategy; SMP outcomes unopened.

## The single biological hypothesis

> **Population recovery does not retrace spatial collapse in colonial breeders.**

A breeding site that has been abandoned is predicted to require a higher surrounding population state to be recolonized than the surrounding population state at which it was abandoned.

For the same SiteID:

[
H = A_{recolonize} - A_{abandon}.
]

Primary prediction:

[
H>0.
]

## Why this is stronger than the current concentration story

The existing penguin results establish:

1. decline can concentrate breeders beyond proportional thinning;
2. increasing regional networks do not necessarily restore effective breeding-site number.

Those results show weak spatial reversibility but do not directly compare extinction and recolonization of the same place.

The SMP test does.

By pairing abandonment and later recolonization within the same SiteID, the test controls stable place identity and asks whether **history changes the population threshold for occupancy**.

## Competing hypotheses

### Reversible site-quality / basin model

For a stable site with fixed intrinsic quality, occupancy should be approximately a reversible function of surrounding population state.

Prediction:

[
H approx 0.
]

### History-dependent spatial recovery

If occupied sites gain persistence from colony state, site fidelity, conspecific cues or other positive feedback, losing occupancy changes the state of the site.

Prediction:

[
H>0.
]

The test is about history dependence. Social Allee effects are one possible mechanism, not the estimand.

## Evidence sequence in one paper if SMP passes

### Part 1 — discovery in Antarctic penguins

Palmer + Signy:
non-proportional concentration during decline.

MAPPPD:
regional effective breeding-site number can remain reduced while abundance increases.

Interpretation:
population recovery need not immediately reconstruct prior spatial organization.

### Part 2 — prospective test in SMP seabirds

For each completed SiteID vacancy spell:

- identify abandonment without using magnitude;
- identify later recolonization without using magnitude;
- freeze the exact spell roster;
- only then open surrounding population magnitudes;
- calculate paired hysteresis width H.

Primary macro inference:
equal-species mean H with one-sided species-level sign-flip test.

### One-paper conclusion if H > 0 is supported

> **Spatial collapse and spatial recovery follow different population thresholds in colonial breeders.**

This would convert the penguin observation from a descriptive anomaly into a general island-ecology process.

### One-paper conclusion if H is not supported

Do not force the synthesis.

Submit the current penguin paper as a bounded Antarctic concentration paper and report SMP separately as a falsification of the hysteresis generalization.

## Island-ecology framing

Classical occupancy models often treat colonization and extinction as rates conditioned on place and regional abundance.

The focal hypothesis is that these transitions are not reciprocal:

[
P(colonizationmid N,site)

eq
1-P(extinctionmid N,site)
]

because current occupancy changes future occupancy dynamics.

The same physical breeding island can therefore have two different demographic thresholds depending on its history.
