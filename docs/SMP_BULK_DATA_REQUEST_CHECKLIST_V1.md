# SMP bulk-data request — analysis-field checklist v1

This is a technical request checklist, not yet an email submission.

## Research purpose

We are evaluating whether long-term component-resolved seabird counts can support a pre-registered comparative test of how breeding distributions change during population decline.

The structural audit must be completed before count outcomes are analysed.

## Requested scope

Prefer all colony-count records required to evaluate support, rather than preselecting only declining species or known key sites.

Time window: 1986–latest fully validated year, with older compatible colony-count records retained when identifiers can be crosswalked.

Taxonomic scope: all SMP species with colony-count data.

Geographic scope: Britain and Ireland SMP coverage available under the applicable data-use policy.

## Required fields

Please include, where available:

- species;
- count date and breeding season/year;
- country / region / county;
- master-site ID and name;
- site ID / site code and name;
- plot/subsite ID and name;
- parent master-site/site/plot relationships;
- whole-colony / partial-site / study-plot indicator;
- merged-site indicator;
- method code and method description;
- count unit;
- count;
- estimate / range / accuracy fields;
- validation status;
- record comments;
- site definition;
- any identifier history or crosswalk documenting site/plot renaming, splitting, merging or boundary changes.

## Key structural question for the data team

Are site codes and plot/subsite identifiers intended to refer to the same geographic monitoring unit through time? If not always, is there a versioned crosswalk or change log that allows persistent units to be reconstructed?

## Analysis boundary

Before receiving / opening biological count magnitudes, we will use identifier and support metadata to freeze eligible species × master-site panels. We will not select panels based on observed decline or concentration effect size.
