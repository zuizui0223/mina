# Ross inverse-path mismatch context audit v1

**Status:** post-result descriptive calibration against other universal down->up episodes in the same frozen six-component Ross series.

## Why this audit matters

The focal 1999 -> 2001 -> 2002 natural experiment has:

    aggregate loss restored = 96.97%
    inverse-path allocation mismatch = 9.41%
    loss/rebound cosine = 0.99695.

The 9.41% number should not be presented as intrinsically large without context.

## Comparable Ross triplets

Within the frozen complete six-component series, identify successive observed triplets in which:

1. all six components decline from the first to second state;
2. all six components increase from the second to third state.

There are three such triplets.

### 1989 -> 1990 -> 1991

    loss = 35,834
    rebound = 12,466
    fraction of loss restored = 34.8%
    inverse-path mismatch = 9.12%
    cosine = 0.99411.

### 1999 -> 2001 -> 2002 — focal mega-iceberg episode

    loss = 112,613
    rebound = 109,198
    fraction of loss restored = 96.97%
    inverse-path mismatch = 9.41%
    cosine = 0.99695.

### 2002 -> 2003 -> 2004

    loss = 78,374
    rebound = 95,679
    rebound / loss = 122.1%
    inverse-path mismatch = 10.63%
    cosine = 0.98391.

## Interpretation

The focal 9.41% mismatch is **not unusually large** relative to the other universal down->up episodes available in this same series.

All three mismatch fractions are around 9–11%.

Likewise, all three loss/rebound vectors are strongly aligned.

Therefore the paper should not imply:

> the mega-iceberg rebound caused an exceptionally large spatial mismatch.

The distinctive feature of the focal episode is instead:

- an independently documented regional disturbance;
- the largest loss among the comparable triplets;
- **near-complete aggregate restoration** within the immediate rebound;
- an ecologically interpretable colony-specific access geometry.

## What this does to the focal claim

Keep:

> 96.97% of aggregate shock loss returned, while 9.41% of rebound allocation differed from exact spatial reversal.

Add the calibration:

> the magnitude of this allocation mismatch is comparable to other down->up episodes in the Ross series.

This makes the paper more accurate.

The ecological value of Ross is the **natural experiment and reference state**, not an unusually extreme mismatch magnitude.

## Consequence for novelty

Do not sell 9.41% as a large or exceptional effect.

The useful result is:

> near-complete numerical restoration can coexist with ordinary-scale compositional slippage.

That framing also explains why prospective Bird/Emperor tests are necessary: the broader contribution concerns the distinction between aggregate and spatial states, not an extreme Ross anomaly.

## Boundary

This is descriptive context only.

The three triplets are not independent experimental replicates and no null distribution or significance test is constructed from them.
