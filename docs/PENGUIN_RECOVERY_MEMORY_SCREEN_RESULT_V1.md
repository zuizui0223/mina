# Penguin recovery-memory screen — result v1

## Bottom line

The existing Palmer + Signy component-resolved penguin panels **do not contain enough completed empty→reoccupied spells to test the proposed hysteresis threshold**.

What they do show is striking but different:

- **22** exact positive→zero loss spells across **21** distinct breeding components.
- Only **1/22** spells was ever followed by exact reoccupation within the monitored window.
- No reoccupation occurred within **2 years (0/21 eligible losses)**, **3 years (0/19)**, **5 years (0/18)** or **10 years (0/17)**.
- The only completed return was Humble component 1.1: zero in **1998**, positive again in **2014**, a **16-year** gap.
- Its frozen same-site contrast was **H = -1.858**, corresponding to a surrounding-state ratio of **0.156**, the opposite direction from the proposed H>0 return-threshold prediction.
- Only **one** informative case had surrounding population state later recover to/exceed its loss-state level while the component remained empty: Signy Adelie **A64**. Its later surrounding state reached about **1.25×** the loss-edge state but A64 remained zero through 2019.

## Interpretation

The descriptive result is therefore not “recolonization requires a higher population threshold.”

Instead:

> **Exact local breeding-site loss is highly persistent in these declining penguin series, but the data rarely revisit the same demographic state after loss.**

That distinction matters. Most components disappear while their parent population continues to decline. Therefore 21/22 nonreturns cannot by themselves distinguish:

1. true history-dependent recovery failure;
2. simply never regaining enough population pressure for recolonization;
3. persistent environmental degradation;
4. monitoring/component-definition effects.

The adequacy gate was fixed at >=10 completed spells, >=5 distinct completed components and >=3 population trajectories. Observed support was **1, 1 and 1**, so the gate fails decisively.

## Consequence for the new research line

The generated process hypothesis remains:

> **Breeding-site loss may create functional isolation that later constrains spatial recovery.**

But the present data family cannot test the causal hinge. The next valid dataset must contain:

- a real **decline → recovery** trajectory;
- fixed, component-resolved breeding sites;
- explicit numeric zeros rather than missing observations;
- multiple **0→1 reoccupations**;
- enough years after loss to compare equivalent surrounding population states;
- ideally island distances / habitat covariates to separate geographic isolation from social-history effects.

No low-count pseudo-absence threshold or alternate roster should be introduced to rescue Palmer/Signy.
