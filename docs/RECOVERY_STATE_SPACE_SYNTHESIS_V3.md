# Breeding-recovery state space v3 — abundance, redundancy, dominance, and path

**Status:** post-result conceptual synthesis.

## Core point

A colonial breeding system cannot be described by total abundance alone.

At minimum track:

1. breeding abundance N;
2. abundance-weighted spatial redundancy E;
3. dominant-node identity / compositional turnover;
4. disturbance/recovery path through time.

The fourth item is not another scalar index. It is the process history required to interpret the first three.

## Ross shows why path matters

Ross Island does not follow one monotonic "recovery" vector.

### Pre-shock -> shock

1999 -> 2001:

    N down
    E up
    dominant Crozier loses share.

### Shock -> immediate rebound

2001 -> 2002:

    N up
    E sharply down
    Crozier regains and exceeds its prior share.

### Longer recovery

2002 -> 2012:

    N up
    E modestly up
    Crozier loses a little share to Bird.

Thus one system visits three different N/E directions in succession.

## Heard shows dominance turnover

At Heard Island Spit Bay:

    total breeding counts rise at every observed interval
    E rises and falls
    dominance changes North -> South.

Therefore even with one sign of N change, spatial recovery can be non-monotonic and can change which node dominates.

## Beaufort shows spreading under capacity release

2004 -> 2010:

    N up
    E slightly up
    small/new subcolony gains share.

Published movement/habitat evidence is consistent with newly usable local capacity changing spatial allocation.

## Why endpoint quadrants are insufficient

A simple N/E state diagram is useful but incomplete.

Two systems can share:

    delta N > 0
    delta E < 0

while differing fundamentally:

- Ross frozen endpoint: starts from a disturbance trough and contains an early re-concentration pulse plus later partial spreading;
- Heard long endpoint: passes through equalization and reverses dominant identity.

Therefore endpoint signs should be accompanied by temporal path and composition.

## Exact local geometry

For E = 1/sum(p_i^2):

    d log(E)/dt = 2(r_bar - r_D).

This gives the instantaneous direction of spatial redundancy.

The sign can change over time because the p_i and local growth rates change.

Ross provides an empirical sequence of sign changes:

    shock: E up
    rebound: E down
    later recovery: E up.

## Monitoring implication

Recovery monitoring should distinguish:

- total breeding abundance;
- occupancy/persistence;
- spatial redundancy;
- dominant identity;
- whether the system is in disturbance, immediate rebound, or longer recovery.

The same current N can occur on different branches with different E.

## Hysteresis boundary

Ross matched-abundance pairs show branch dependence:

    ~204k pairs:
    1997 E3 1.626
    2002 E3 1.507

    ~222k pairs:
    1985 E3 1.625
    2004 E3 1.413.

This is consistent with hysteresis but does not prove endogenous memory because environmental conditions differ.

Prior work already demonstrates Adélie subcolony-level hysteresis.

The new generated question is whether local configuration memory propagates upward to colony-level allocation of rebound.

## Claim ceiling

Supported:

> breeding recovery is path dependent in spatial composition; disturbance, rebound and longer recovery can move redundancy in different directions.

Supported across Ross + Heard:

> total breeding abundance can increase while spatial redundancy follows a non-monotonic trajectory, and dominant identity may either persist or reverse.

Generated:

> local configuration memory and dynamic capacity determine which spatial recovery path occurs.
