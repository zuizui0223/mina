## 2. 推定対象と対象行

### Q2・Q3の主解析

主応答 Y はStep 1の `concentration_excess_decade`、すなわち二時点の log Simpson集中変化から、両時点の総数とpooled site sharesを使う有限計数帰無の平均を引いた10年当たり変化である。正を過剰な集中とする。帰無B=20,000、seed基準20261106と行別seed、入力整数条件はStep 1から引き継ぐ。

対象は `analysis_role=macro_primary` の重複しない計数行であり、減少・増加・不変のすべてを含む。原構成単位集合と二時点が固定され、同期、同じ原計数単位、非負整数、K≥3、N0・N1≥2、経過年数>0を満たすことを要する。モデルに用いる空間幅は全固定単位の比較可能な座標から求め、幅>0のときだけ自然対数を取る。幅0や未取得座標を小さい正値へ置換しない。

Palmer・Signy・Rossの島内行は `local_resolution` として同じ論文の解像度別パネルに置き、上位MAPPPD行と独立反復として合算しない。皇帝のN_meanに基づく行は `model_index_reference` とし、共同事後サンプルがない限り有限計数補正を作らず主検定へ入れない。起点・終点の総数0は台帳と記述に残し、対数変化や集中を疑似計数で定義しない。終了年を「最後に正だった年」へ移すことも禁止する。

Q2とQ3は必要説明変数が異なるため、**別々の事前定義された対象行集合**を持つ。英国SSTの未確認を理由に、形質値がそろうQ2まで一律に止める設計にはしない。各検定で、候補行数から欠測理由別の除外までを記録する。

### Q4の種ペア台帳

Q4の主検定も重複しないマクロネットワークを対象とし、島内行は解像度の比較に残す。種ごとの主表で選ばれた年対が一致することを必須条件にはせず、**別のpair endpoint registryを効果量の計算前に固定**する。

1. 元から期間固定の対象はその期間を保持する。JNCCは両種の共通地理単位について、早期・後期それぞれの実調査年が種内・種間とも厳密一致することを必要とする。候補年対が複数あれば、最も早い開始年、その開始年で最も遅い終了年を選ぶ。別年の調査を同時点に見せない。
2. MAPPPDの種ペアでは、両種が両時点で比較可能な方法により調査され、共通の地理的構成単位が3以上ある年対を、観測有無・ID・方法だけで列挙する。最も早い開始年を選び、その開始年の中で最も遅い終了年を選ぶ。集中・増減・気候の値を選択に使わない。
3. 選んだ共通集合で両種の計数、総数、G、構成比を改めて計算する。異なる集合を使う主表のGを転記しない。原単位は各種の二時点で一致させ、異なる種の絶対計数は合算しない。
4. 四つの総数 N_a0、N_a1、N_b0、N_b1 がすべて2以上で、原計数が比較可能な非負整数のときだけ補正重複 Z を推定する。いずれかの総数が0なら候補を残し、Z・D_pairはNAとする。別年対へ取り替えない。
5. 未調査種を0埋めしない。Signyの別種固有ラベルを共通区画と仮定しない。共通単位がない場合は「重複なし」という結果ではなく、推定不能として残す。

Z はStep 1で定義した O=Σmin(p_a,p_b) の10年当たり変化から、種ごとの固定潜在配分を仮定した二時点帰無の平均を引く。種ごとの原計数単位・総数を用い、同じ観測過程や種間競争を再現する帰無とは解釈しない。

## 3. Step 2で固定する説明変数

既存リポ内の文献・出典・データだけを使う。各値には出典の固定コミット／識別子、引用箇所、原定義、種・個体群・季節、単位、抽出値、採否理由を付ける。結果の種別順位を参照して値や分類を選ばない。

| 項目 | 草案の操作的定義と固定事項 |
|---|---|
| 固執性 F | **成鳥が次の繁殖機会に同じ繁殖地を利用する固執性**。比較可能な既存資料では0–1の年次割合を候補とする。出生地への帰還、単なる生存率、検出されなかった個体を含む見かけの帰還率とは区別する。対象となる繁殖単位・分母・観測間隔、複数出典の採用順と統合規則を固定する。定性的な「固執的」という記述から数値を作らない |
| 渡り | 留鳥・部分渡り・渡りの区分と、その対象個体群・季節を固定する。不明を留鳥にしない |
| 食性幅 | 比較可能な餌カテゴリー・季節・算式が明示された既存指標に限る。異なるカテゴリー数や標本努力の違う胃データから、そのまま種固有の幅を作らない。共通定義が成立しなければNA |
| 営巣密度 | 比較可能な営巣面積当たりの繁殖数。原計数単位と面積の定義を保持し、島全面積と営巣パッチ面積を混ぜない。単なる個体数や構成単位数を密度の代用にしない |
| SST変化 W | 実際の海面水温（SST／tos相当）の端点差を同じ経過年数で10年当たりに換算。各ネットワークの生態計数の二端点に対応させる。tas／気温や深度が異なるthetaoをSSTとして接続しない |

今回の主たる種特性検定はFの1件である。渡り・食性幅・営巣密度は凍結した種特性表に保持するが、下記主モデルへ結果を見て追加・削除しない。別の主仮説へ昇格する場合は関連を計算する前に計画改訂が必要である。

気候について、出典・変数名・深度・単位、格子解像度、沿岸マスク、地点からの距離規則、集約する海域、季節／月、端点年または固定した平均窓、欠測許容と空間重みを**Step 2で決定し固定**する。少なくとも同じSSTという変数・同じ時間的対応を満たさない資料を単に標準化して混ぜない。英国ネットワークの既存SST入力は未確認であり、入力がそろったとは主張しない。既存範囲で確認できない行はNAのまま残す。

Fの文献識別子・種別値、気候の入力と集約規則は未確定である。これらが未確定のままQ2–Q4を凍結済み・実行可能な計画と表示しない。

## 4. モデル・判定・感度分析

### 主モデル案

Gは記録総数の10年当たり対数変化、Kは固定構成単位数、Eは幅km、dtは経過年数とする。logは自然対数である。

```text
Q2: Y ~ F + G + log(K) + log(E) + dt
        + (1 | species) + (1 | dataset) + (1 | network)

Q3: Y ~ W + G + log(K) + log(E) + dt
        + (1 | species) + (1 | dataset) + (1 | network)
```

Q3は総数変化Gを条件とする気候関連であり、温暖化の総効果や因果的な直接効果の推定ではない。ネットワークIDは種を含まない共通の地理的親IDである。既存原計数の二重使用は事前に除き、出典のランダム効果を重複除去の代わりにしない。

Q4では共通集合上で G_a、G_b を求め、

\[
D_{pair}=-(G_a+G_b)/2
\]

とする。正はペアの平均的な減少であり、両種が必ず減少していることを意味しない。

```text
Q4: Z ~ D_pair + W + log(K_pair) + log(E_pair) + dt
        + (1 | network) + (1 | dataset) + u_a + u_b
```

u_aとu_bは**同じ種ID集合・同じ分散成分を共有する交換可能な種の複数所属効果**である。種の並び順で別々のランダム効果に分けない。これは同じ種が異なるペアへ現れる種レベルの依存を扱うが、同じネットワークのAB・ACペアが同じAの計数を使う残差依存まで解消するとは仮定しない。Q4の不確実性法は、**同一ネットワーク内の全ペアを一つの依存ブロックとして保持する方法、または同等の共分散を明示した方法**をStep 3で固定する。ネットワーク切片だけを根拠に、ペア行の独立残差を生成するブートストラップを採用しない。

SSTが欠けるペアはこの事前定義したQ4モデルでは推定しない。結果を見てWを削除したモデルへ置換しない。

各行を等重みにし、元個体数や帰無SDで逆分散重み付けしない。各検定で行数、独立ネットワーク数、種数、出典数、国／地域別支持を別々に示す。多数のネットワークを、多数の独立な種特性の反復と数えない。種ランダム効果は系統共分散の制御ではない。

### 四主検定の判定

H2、H3、H4D、H4Wを一つの検定族とし、**両側p値にHolm補正、族全体α=0.05**を適用する。予測支持は「対象係数が正、かつHolm調整p<0.05」の両条件を必要とする。負で同じ基準を満たせば予測に反する。区間が広い・調整pが基準を満たさない場合は不明瞭とし、無効果の証明とはしない。

未推定の仮説は推定値・p値をNAで報告する。残った仮説だけへ検定族を縮めない。計算上は未推定枠をp=1として四枠のHolm補正を行えるが、この1を実施した検定のp値として表示しない。点推定と95%区間を必ず併記し、区間が個別係数の区間か同時区間かを区別する。

### 推定・不確実性エンジンの候補

Q2・Q3の候補はGaussian混合モデルの最尤推定と、対象固定効果を0に制約したモデルからの両側パラメトリック・ブートストラップである。提案回数は9,999、seed基準20261106。毎回同じ固定効果・ランダム構造で再適合し、対象係数の絶対studentized statisticに基づく極端割合を用いる。Q4は上の共有計数ブロックを保持する方法を別途固定する。観測効果の区間はその推定法に対応する区間として算出し、Step 1の有限計数帰無区間を流用しない。

**実装・版、区間構成法、分散境界と収束失敗の判定／処理、Q4の共有計数に対応する不確実性法は凍結時の未決事項**である。複数所属効果を同じ分散成分で実装でき、共有計数による依存を保てることを、合成データだけで確認してから一本に固定する。独立ネットワークの支持が足りず適切な区間を構成できなければQ4は記述にとどめ、主検定を未推定とする。新しい依存ソフトが既に導入済みとは主張しない。実データで有利なp値を与えるエンジンを選ばない。

### 事前指定する感度と欠測

- 出典の水準数が少ないため、**datasetを固定効果に替え、それ以外を同じにするモデル**をあらかじめ感度分析とする。主モデルが特異・推定不能の場合、その状態を報告し、固定効果版を有意性によって主解析へ昇格しない。
- **年率化の感度**として、同じ対象行でY・Zを全期間の変化へ戻し、GとWも全期間の対数総数変化・温度差へ戻したモデルを示す。dtは説明変数に残す。これを主結果が弱い場合の代替検定にしない。
- **3年平均の感度**はStep 1に従い、主端点の年を含む最初の3暦年・最後の3暦年について、同じ構成単位の全年度が実測され、両窓が重ならない行で実施する。経過年数は両窓の平均観測年の差とする。共通シェアは6年の元整数計数をプールして定め、各年の元総数で独立に帰無を生成してから、観測と同じ年平均・集中計算を行う。対象条件を満たさない行は補助値をNAとし、窓を広げたりJNCCの非同期調査や不足年を埋めたりしない。
- 欠測・非同期・原単位不一致・未回収・不適格計数は理由別に保持する。共変量の平均代入、未知の固執性の分類、未調査を0とする補完は行わない。使用可能な国・地域だけに対象が限られれば、その対象範囲の結果として示す。
- 南極内の海氷減少は補助関連として、対応する固定気候仕様で報告する。主たるSST仮説の代替成功判定には使わない。主仮説の閾値・方向・対象行・モデルは感度結果で変更しない。

## 5. 凍結の順序と将来曝露

凍結順序はユーザー指定の工程を維持する。

1. **Step 1**：既存原本と行系統を回収・対応づけ、ネットワーク×種の端点台帳と種ペア端点台帳を固定する。共通効果量を作り、ゼロ・欠測・非推定理由を含む表を完成させる。
2. **Step 2**：既存資料から形質表・気候入力・集約規則を確定し、引用と値の採用規則を保存する。入力不足はそのまま記録する。
3. **Step 3**：本草案の未決事項、主検定の対象行、計算実装・不確実性の算出法を確定し、ファイルhashとcommitを記録する。その後にのみ新しい形質・気候・重複の関連を適合する。外部登録する場合は、既閲覧結果と分析段階を同じ文面で開示する。
4. **Step 4–5**：固定したモデルを実行した後、既存CMIP6入力の対象・変数・モデル・実験・期間を固定した将来曝露を計算する。Step 4の符号に応じて将来条件を選ばない。
5. **Step 6**：集中の共通尺度、形質・海洋変化との関連、種間配分、将来曝露を一本の論文に統合し、ローカル解像度と皇帝モデル指数の役割を明示する。

将来の種別曝露は、今回含まれる対応監視ネットワークのうち、重複を除いた集合の**後期観測総数を固定した重み**で集約する。種sについて、原計数単位が比較可能な集合内で w_gs=N1_gs/ΣN1_gs とし、将来にも同じ重みを使う。AON・IND・モデル成鳥指数など異なる原単位を絶対個体数として合算しない。ネットワークごとの後期観測年を併記し、同一暦年の全球分布とは表示しない。空間・時間・物理変数の対応を確認できない曝露はNAとし、欠測を0変化に変換せず、監視集合の重みで測った気候入力被覆率を示す。これは種全体に対する個体群被覆率とは異なり、後者を既存資料で確認できなければ不明と記載する。

この集計は**今回含まれる対応監視ネットワークの後期分布に基づく、将来の水温・海氷変化への曝露**を表す。種全体の繁殖分布を完全に代表するとも、将来の個体数、繁殖場所への移動、集中、種間競争を予報するとも解釈しない。Q2–Q4の観測関連だけから将来の分布重みを更新しない。
