# 繁殖分布の集中を比較する統合マクロ解析

**状態：2026-11-06、統合設計・表仕様・事前分析計画の草案を作成。新しい統合効果量、形質・気候との関連、将来曝露は未計算。**

## 一つの中心質問

**個体数が変化するなかで、繁殖分布は比例的な増減を超えて少数の場所へ集中するか。その強さは、種の営巣地への固執性と海洋環境の変化に対応するか。**

JNCCの海鳥、MAPPPDのPygoscelis、皇帝ペンギン、Palmer・Signy・Rossを、固定した繁殖単位の二時点比較として一つの台帳に入れる。Q1は共通尺度での集中の記述、Q2は種の特性、Q3は海洋変化、Q4は同じ場所を調査した種間の重なりである。将来計算は、この分布が置かれる物理的曝露を示す。

既存のPalmer/Signy集中、英国の二時点再配置、皇帝の配分指数、Signy食性の肯定結果は、元の推定対象・仕様の結果として保存する。今回の主応答は繁殖分布の集中に統一し、食性・繁殖時期・GPS解析はこの主モデルへ追加しない。既存英語食性稿は保存済みの成果であり、現在の作業目標はこの統合表である。

## 今確認できた入力状態

- MAPPPDの一意な地点×種×季節表、皇帝の著者公開推定表、Rossの元計数は現ブランチにある。
- JNCCの17種版は既存ブランチ `research/jncc-v32-mechanism-contract` の固定コミット `0f913ecfd4fd03e328dc1a6c78c77e451a99fe9e` にある。保存物はコード・仕様・集約結果で、原XLSXはGit管理外。元URL・SHA・サイズは記録済み。取得済み成果物の検索では集約結果が見つかったが、原XLSXは見つからなかった。
- Palmerの現存表は島合計で、島内区画の再計算には既存原本の回収が必要。Signyの現存区画表は2012–2019年のみなので、元仕様の1996–2019年を勝手に短縮しない。
- 英国SSTの保存済み値は確認できていない。南極の既存表にもSST、表層ポテンシャル水温、気温の違いがある。Step 2で同じ変数・期間の既存入力を確定するまでQ3を実行済み／準備完了とはしない。

これは新しい出典を探す計画ではない。同じ凍結済み入力の回収と、既存資料の統合を次工程とする。全行がすべての検定に使えると仮定せず、NAと理由を残して台帳を完成させる。
