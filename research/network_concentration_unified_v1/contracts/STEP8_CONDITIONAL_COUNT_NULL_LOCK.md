# Step 8 — JNCC固定周辺計数（超幾何帰無）での頑健性監査

## 新たな問い（既知の肯定結果後の探索的感度）
JNCC原Site.IDの二時点対応計数を使った既存のY_excess正436/663は、**帰無の数え方を固定周辺計数型へ変えても同じ方向か**。

従来のStep1は元の各端点総数N0,N1に条件付け、共通シェアp_pool=(n0+n1)/(N0+N1)で各端点を独立多項分布により20,000回標本化する。

新たな補助帰無は、元の各Site.IDの二時点合計m_j=n_j0+n_j1と二時点総数N0,N1の **両方を厳密に固定する**。第1時点の計数を多変量超幾何分布 Hypergeom(m, N0)から生成し、第2時点はm−n0*とする。同じ固定Site.ID集合と年を保持。新しいデータ取得・元調査誤差推定はない。

## 固定済み手順
- 入力：元公式JNCC比較XLSX（SHA256 9edf05b8af0a44c3ca770f390120c4b99bcaae3ae35fd844a82982d6ad8116d4）、元の固定端点台帳、変更不可のnetwork_species.csv（Git blob e089c4525226c156a1554ce4f480a7611c946ae7）。対象は元のJNCC主解析663行のみ。南極MAPPPDと旧島内結果は別階層としてそのまま保持する。
- 全行に1999回、乱数generator=NumPy PCG64、seedは20261107＋元row_idのSHA256先頭8桁から決定。条件付けた超幾何分布の二時点Y_raw(10年換算)を計算して補助帰無平均を算出し、Y_excess_hyper=Y_raw_original−E_hyper(Y_raw*)とする。元Y_excessは再計算で置換せず、値・符号・原p_pool多項帰無を保持。
- **検証**：三つの元構成単位の玩具計数に対して、すべての条件付き配分状態を組合せ確率で厳密列挙した帰無平均を求め、サンプル版との近似一致を確認する。元Y_raw、元N0/N1、Site.ID集合、元K、計数単位が不一致なら全体STOP。
- **事前に全て報告**：新しい帰無で正の行数と割合、元の正436行のうち正方向維持数／逆転数、元の非正227行からの正転換数。17種の単純な種別平均符号数と種等重み平均。減少479行の正方向数。元Country全6カテゴリ、元計数単位5カテゴリ、17種それぞれの結果。平均帰無差とMC標準誤差。正負以外に新しい検定p値や多数の代替帰無を追試しない。
- 現在の主要結論は前出の「元JNCC共通表663の過剰集中436（65.8%）、17種15種が正、減少479中324正」。補助帰無で減っても、元の主結果や固定H3/H4回帰・p値を差し替えない。
- 使用する超幾何帰無は**真の生態学的変化・観測誤差を較正するものではない**。両端の実際のSite.ID計数を条件としているため元の多項帰無と推定対象が違い、真の調査努力・ポリゴン変更・検出精度がない問題は残る。共有ネットワーク間の空間依存を解消した推定でもない。
- 今回も既知の結果を閲覧後の探索的感度試験であり、独立の事前登録・証明された気候因果・島嶼機構とは呼ばない。試験の定義と閾値は実際の新しい正方向の数を見る前に固定し、良い結果に合わせて変更しない。
