# Step 5 固定繁殖ネットワークの将来物理曝露 — 範囲・対応規則

2026-11-07、固定計数構造へ既存CMIP6値を新たに結合する前の実行仕様。これは**生物応答予測ではない**。Step4 H3/H4は支持されなかったので、係数を未来の繁殖個体数や集中へ外挿しない。

入力: Step1 固定端点台帳と一時的なunit_endpoints.csv、固定network_species.csv（Git blob e089c4525226c156a1554ce4f480a7611c946ae7）、既存 research/climate-penguin/outputs/cmip6_exposure_atlas_v1/site_scenario_exposure.csv（Git blob 9d7badfd2ad077047cb6f20accc74e3738cf4648）。後者は3モデル×2SSP×2期間の106固定座標であり、macro_40の原MAPPPD地点が40ある。

実施対象: 主解析675行のうちMAPPPDの共通計数帰無適格**12ネットワーク×種行**（Adelie / chinstrap / gentooのみ）。英国JNCC 663行には現状のCMIP6座標源がないため、欠測を0にせず、この曝露表から全面的に除外する。皇帝の著者モデル指数、Ross/Palmer/Signy島内区画は同じ原計数の重複として足さない。

- original MAPPPD Site.ID（先頭MAPPPD::を外す）とCMIP6 original cohort=macro_40 のsite_idを照合。最初に、原Site.IDに対応した静的WGS84座標の地理距離が0.5km以内か検証する。識別子がない／座標がずれる地点はNA。別cohort phenology座標や最寄り地点へ代入しない。
- 共通二時点の**後期のみ**から監視構成単位の巣数N1、元のK、元のnetwork_id、年を取得。原調査計数値はnullとゼロを区別し、同一Site.ID一度だけ。同じ計数を別の地域に再利用しない。
- 各ネットワークで元の固定構成単位KすべてがCMIP6地点に対応するときのみ「完全一致」、一部だけなら「部分一致」として実測Kと後期巣数の対応率を両方報告し、主たるネットワーク曝露値はNAにする。
- 大気tas（空気温度）はマクロ地点と座標を照合できた完全一致ネットワークで、元のStep2 W定義に合わせて**元Site.IDを等重み**で平均。気候モデル海氷siconcと海面塩分sosはさらに全地点が3気候モデルとも海洋セル50km以内（marine_all_3_models_within_50km=1）でない限り主値NA。部分一致の気候差は別の記述的被覆表へ保持するが、足りない地域へ代表値として補わない。
- 種別曝露は、両端が固定され完全一致のnetwork×speciesだけを使って、後期ネットワーク総巣数N1を固定重みとする。モデル間差を単一独立サンプルに数えず、3モデルの元アンサンブル平均を各地点からネットワーク・種別へ集約する。総対象12行の後期巣数に対する被覆率と、ネットワーク完全一致率を別々に示す。別調査年の後期N1を合算した「監視対象の固定分布重み」であり、同一時点の全球種数ではない。
- 全4組（SSP2-4.5/SSP5-8.5 ×2041–2060/2081–2100）を保存。未来の種数・絶滅率・集中Y・種間競争や分布移動を予報したとは扱わない。空気温度・海氷・塩分の3軸の物理曝露だけである。
- 元のStep1生物指標とStep4の支持なし結果は保存。入力・場所・調査数・観測範囲を結果に基づいて変更しない。
