# Regional historical core versus remainder — bounded descriptive macro extension

Purpose: extend the already documented Palmer/Signy dominance contrast to Antarctic regional breeding-site networks without refitting the frozen Ecology Report. Previously published repo results include Palmer loss of initial dominant codes (3/3), Signy retained dominant units (2/2), and non-generalizing Antarctic fixed-roster concentration. Do not repeat endpoint rank comparisons as a new discovery. This extension asks whether a core identified in an earlier, disjoint decade has higher or lower subsequent nest-count retention than other monitored sites in the same reporting region.

Fixed data: PR214 branch analysis/penguin-decade-redistribution-v1-20261110, research/climate-penguin/macro_panantarctic_v1/allocation_20261115/original_three_decade_43_source_site_species.csv, blob a5ccb7a527605d28804ef389109f416bd6dea090. Original-derived decadal medians, no imputation; 43 distinct site-species rows, >=2 actually observed years in each of three decades, 19 Adélie/12 chinstrap/12 gentoo. Existing outcomes known at broader scale; exploratory, not independent prospective replication. Input includes existing archive medians rather than newly retrieved original censuses. Before new endpoint calculations, inspected schema, region/species group sizes and block coverage only in this turn.

Define 1991–2000 historical core as unique maximum site median within each species × original reporting region; all others fixed remainder. No new geography threshold or outcome-based size cut. Require >=3 sites, unique positive core in first decade, positive 2001–2010 subtotal for core and remainder, and positive combined subtotal in final decade; otherwise report gate failure. 2001–2010 and 2011–2020 form disjoint evaluation periods; historical size is not used as denominator. This avoids direct mathematical coupling from using the same early count as both rank and growth denominator, but does not eliminate measurement noise, autocorrelation or persistent site differences. Include recorded zeros as observed; never fill missing.

For every eligible group report core ID, 3-period shares, core and remainder middle-to-late retention ratios, difference in relative share, and regional subtotal change. Core excess under proportional thinning/growth = observed late core minus its middle share times late total. Decompose net absolute count change into core and remainder, separately label declining and growing observed subtotals. All counts are sums of site-specific decadal medians with potentially different census years (NOT synchronized regional populations). Report leave-one-remainder-site-out range for share change, keeping original historical core fixed. Do not remove core and rerank as a rescue; no significance test, regression or pseudoreplicate sites as regions. Sensitivity excluding the entire original block of the core is not meaningful for the same core question; state whether core and remainder share block or occupy separate blocks. Group eligibility and results reported including negative findings. Single-site groups and two-site groups reported separately as structurally ineligible. No new climate causal analysis or claim of geographic centrality; "core" means historically largest counted site, not geographic center or source population.

Stop after this bounded diagnostic. If original monitoring support is only 5–6 regional species groups or fewer declining groups, describe as limited macro-scale comparison and preserve a future independent expansion requirement (new censuses, fixed spatial hierarchies). Do not reopen the frozen Palmer analyses, change main, or launch more parameter searches.
