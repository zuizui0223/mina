# Frozen evaluation design: same-day Chinstrap GPS against marine current fields

**Date:** 2026-11-08 JST. **Status:** prior outcome-aware exploratory; evaluation scores for the new Circuitscape comparison not seen when fixing this contract. Keep on separate Circuitscape PR #211, do not merge into warming v0.6 as a migration mechanism.

## Primary question

Can the sea-ice-dependent **electrical current field** of a hypothetical outward marine-access circuit explain original spatial use by breeding-season Chinstrap GPS better than the identical landscape with **uniform ocean resistance**? No calibration or estimate of natal dispersal, interisland breeding exchange, penguin energetic cost, krill catch, climate-driven abundance, or future colony demography.

## Source/ground model fixed before inspecting current score

For **each island-date**, define original source center from the median latitude/longitude of the *first recorded GPS fix of all source deployments* at that island-year. It estimates breeding-land approach, not a verified nest entrance; no use of the within-day GPS locations to choose its center.

- Original geolocated source-valid ocean cells (status marine bits 1/2 clear; SIC in 0–100) are passable network nodes at 25-km grid grain. No fixed SIC cutoff; a measured SIC of 15/30% is not a physical barrier.
- Spatial domain: all source-valid marine cells within **210 km** (geodesic distance to original first-fix colony center). Source: nearest valid ocean cell within **35 km**, else source unavailable and that island-day unscored. Current sinks: all **source-connected** valid-ocean pixels at distance **175–210 km**. Only the source-connected 8-neighbor component is included; verify it contains ≥8 sinks, and do not invent other exit points. The radial domain and ground belt are *model assumptions*, not physical ecological sinks. Ground resistance zero, source 1 A. No GPS visit pixels used to build the resistance raster, source or sink set.
- Both years and all islands are computed under the same network topology rule: **8-neighbor** for primary comparisons (4-neighbor is a later sensitivity, not selected after scoring).
- Exactly three uncalibrated resistance surfaces, not tuned to GPS: uniform `β=0`, sea-ice obstacle `β=+2`, sea-ice preference `β=−2`, each with cell resistance `R=exp(β*SIC/100)`. Preserve zero and missing SIC distinction. Do not label β+2 or β−2 as a measured penguin preference.
- Run **actual Julia Circuitscape.jl v6 advanced mode**, 1 source and multi-ground within each original island-day, one solve for each β: 45×2×3=**270** planned circuits. `write_cur_maps=True` produces `_curmap.asc` used for evaluation. Preflight check land/no-data alignment, source/sink nonoverlap, source component, and sorted original date roster. Source map+ground maps are kept independent of GPS visit pixels.

## Target and score fixed before running

- For each eligible island-day, map original hourly GPS positions to nearest original source-valid ocean pixel **within 20 km**, as existing source routine does; deduplicate by native pixel **within day**; no imputation for unmatched fixes. Observed GPS positions are locations, not verified foraging/capture events. The same set of GPS observed cells must be used for all three β models.
- Compare each visited cell's **cell current percentile** among original source-connected ocean cells in the same fixed **25-km center-distance bin** (10–35, 35–60, 60–85, 85–110, 110–135, 135–160 km); report the fraction of visited GPS cells scored and support bin sizes. A GPS cell in an ineligible bin, unavailable pixel, unconnected sea component or outside input current grid is **missing**, not zero or a false biological absence. Available marine cells are potential habitat, not empirically surveyed absences.
- Island-day score = mean within-bin percentile over its distinct visited source-valid pixels. Scenario gain = island-day score for β±2 minus β0 score. No parameter selection. Equal-island-year average of island-day gains is the main summary, with per-island-year results and `Signy − other` matched-day differences retained. Individual GPS pixels, tags or days are **not independent regional biological replicates**, and no naive p-value is computed.
- A positive scenario contrast in one year cannot establish movement barrier preference; a strong claim would need consistent signal in distinct island-years with independent held-out tracking or external movement outcomes. If source support of scored island-days is <60/90 or fewer than four of six island-year units have at least three scored days, classify **INSUFFICIENT_VALIDATION_SUPPORT**, do not lower thresholds post hoc. Otherwise report **DESCRIPTIVE_SCENARIO_COMPARISON_ONLY** irrespective of sign; biological `preferred β` is never estimated.
- Null control: at β0 the *geometry and source/ground maps* must be identical to β±2 in each island-day. Julia must write valid, nonnegative current maps with consistent ArcInfo header and finite values at all scored GPS pixels; this is a required numeric gate. Independence check: on at least one source-day, use a separate SciPy sparse resistor-Laplacian solution of source 1A+ground boundary, with cell current calculation, and verify the Julia map within floating tolerance. A failure prevents ecological scoring.
