# 温暖化一本化：気候応答の時間尺度と格子重複の感度監査（2026-11-07）

この報告は、温暖化を主題とする一本化原稿 v0.1 の **事後的・記述的な確認**。新規の独立標本、事前登録された有意性検定、2050/2100年の生物予報ではない。元ソースに固定された9年のSigny表と6地点×4条件のCMIP6物理表から直接再計算した。計算コード: check_warming_unified_sensitivity.py。新規の生物学的アウトカムは追加していない。

## 1. 既存の食性・海氷の正関連は、線形年次傾向だけでは説明できない

Signy 2001–2009年の共通9季節、アデリー349胃＋ジェンツー73胃＝422胃。元データの魚食割合差は **Gentoo−Adélie**、孵化日差は **Chinstrap−Adélie**。気候の独立反復は9年であり422ではない。

| 感度診断 | 魚食割合差×SIC | 孵化日差×SIC |
| --- | ---: | ---: |
| 元のPearson r | +0.7814 | −0.0661 |
| 年次線形トレンドを除いたr | **+0.7649** | +0.1806 |
| tieを処理したSpearman r | +0.7000 | −0.0509 |
| 2003–2009の7年に限定したr | +0.9723 | −0.1478 |
| 9年をIIDと**仮定したときに限る**Fisher 95%区間 | +0.244〜+0.952 | −0.700〜+0.626 |
| SICを循環シフトした9配置で絶対rが元値以上 | 1/9 | 6/9 |

魚食割合差と海氷の正関連は年次の線形傾向除去後にも残る。2003年にアデリーの孵化日ソースコロニーがA41からA39へ変わるため、その前の2年を落とした結果は保守的な比較ではなく**感度診断**としてのみ扱う。循環シフトの1/9は、非定常気候系列の厳密なp値ではない。旧来の3種772胃・3指標補正p=0.0342も、この別の2種422胃解析の独立した検定結果としては再利用しない。

孵化日のrがゼロに近くても、「時間ニッチは温暖化に不変」という同等性の証明にはならない。9年の95%区間は広い。Clewlow et al. (2019) はSignyで季節的非同期と気温応答を既に報告しており、新規性は9つの同年海氷値に別の2軸を照合した部分に限定する。

## 2. 将来の海氷値は「4独立地点」ではない

6繁殖地点のうち海洋格子が原資料で50 km以内と確認できたのは4地点のみ。実際の海洋モデル格子はF030（3地点）とF018（1地点）の**2格子**である。全3モデルの気温上昇・海氷低下という物理的方向は変わらないが、重み付けで海氷変化の代表値が変わる。

| 条件 | 4繁殖地点等重み ΔSIC(pp) | 2格子等重み ΔSIC(pp) |
| --- | ---: | ---: |
| SSP2-4.5 2041–2060 | −11.27 | −12.84 |
| SSP2-4.5 2081–2100 | −19.96 | −28.42 |
| SSP5-8.5 2041–2060 | −13.96 | −16.19 |
| SSP5-8.5 2081–2100 | **−23.94** | **−35.74** |

両列は**異なる推定対象**。4地点等重みは繁殖サイト集合の曝露、2格子等重みは異なる環境格子の単純平均である。格子を独立反復として繁殖地の数へ転用しない。また、6地点平均の将来気温+4.35°Cと4地点/2格子のSICは母集団が異なる。塩分・SST・雪・植生の将来生物応答係数は較正されていない。

## 3. 一つの論文として残す中心命題

**長期の繁殖種構成の変化、年次の海洋食性差、繁殖時期の種間差は、同じ一つの海氷トレンドに還元できない。** 海氷との対応は生態的軸・時間窓・観測粒度ごとに異なる。これは観測的な非同調性であり、温暖化が種交代や競争の変化を直接引き起こした証明ではない。

論文の順序は①同所6地点・2地域のアデリー減/ジェンツー増と長期/計数年SICの窓の相違、②Signy同一年の食性差と孵化日差の別々の関連、③CMIP6の将来**物理環境**（数値的な将来巣数ではない）。Palmer/Signyの繁殖区画集中は異なる解像度の補足成果として保持。JNCC集中・BTO・SMPは別研究とし、本論文の気候反復に数えない。
