# 帰無仮説を課したクラスタ再標本化の感度確認

2026-10-29、実行前仕様。対象は前回と同じ216組。前回の有意結果だけを対象にしない。探索後の追加診断であり、確認的検定ではない。

環境係数ゼロを課し、地点効果／地点＋年効果だけのモデルから予測値と残差を得る。クラスタごとに残差へ±1（Rademacher重み）を掛けて疑似応答を作り、元の環境変数を含むモデルを再推定する。各反復の一方向CR1クラスタ標準誤差でt統計量を標準化し、観測された絶対t以上の割合を両側p値とする。地点クラスタと年クラスタを別々に実施する。

クラスタ数12以下では全2^G重みを列挙。それ以上は固定乱数種で9,999反復し、(超過回数+1)/(反復数+1)を使用。全列挙は重みのMonte Carlo誤差をなくすだけで、厳密なランダム化検定を意味しない。反復の標準誤差が非正／非有限なら反復数と理由を記録し、当該検定を判定不能とする。

地点版・年版の各216組にBH/BY補正を行う。両方式の最大pを使った補正値も感度指標として保存する。地点版はクラスタ間独立、年版は年をまたぐ独立という別々の近似であり、両者の最大pを取っても一般的な二方向依存に妥当な検定を構成したことにはならない。小標本・年ラベル・移行日標本選択の問題を解消しない。

反復係数とクラスタ標準誤差を、少なくとも各モデル・各方式の先頭反復でstatsmodelsの通常推定と照合する。元の係数の一致も確認する。これは数値確認であり、統計的仮定の確認ではない。

参照：[wild cluster bootstrapの実装文書](https://s3alfisc.github.io/fwildclusterboot/articles/wild_bootstrap.html)。今回はPythonで上記アルゴリズムを実装する。
