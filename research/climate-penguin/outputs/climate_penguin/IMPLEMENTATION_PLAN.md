# 気候・海氷・ペンギン繁殖・植生 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 既存minaと公開データから海氷の季節変化・流動と繁殖数／実測行動の関連を広域で検証し、検証済みの範囲を将来気候シナリオへつなぐ。繁殖地の衛星抽出と植生変化を追加する。

**Architecture:** 原データ・出典・観測単位を保存し、地点と季節の対応を監査してから、環境指標、観測モデル、過去の外部検証、将来シナリオを順に構築する。カタログ上の可用性と実際の解析可能性を分ける。

**Tech Stack:** Python/pandas/numpy/xarray/rasterio、公開STAC、OSI SAF、CMIP6公開アーカイブ。既存凍結結果は変更しない。

**Spec:** REMOTE_SENSING_SPEC_V1.md、phenology_audit.md、../ice_asymmetry/FEASIBILITY_JA.md。

## Global Constraints

- 繁殖数・定着日・産卵日・糞面積は異なる応答。代理指標を実測行動と呼ばない。
- 非観測をゼロにしない。同名地点、暦年、繁殖季、カメラ、計数方法の対応を確定する。
- 氷の退去日は融解だけで決まらない。全南極に一律の移動方位を仮定しない。
- 仮説・窓・閾値を効果推定の前に固定する。新規研究を既存凍結結果の事後説明にしない。
- マクロ解析を2地点へ縮小しない。画像の校正地点と主解析の母集団を区別する。
- 未来の植生・行動は条件付き予測。日次情報のない月次海氷から日次精度を主張しない。

## Review Focus

独立性、観測努力、同時原因、逆因果、追跡の帰還個体偏り、空間外挿、海氷流速の座標軸、雲・積雪・残留糞の分類誤差。月次CMIP6はモデル格子のX/Yを地理東西南北へそのまま読み替えない。
