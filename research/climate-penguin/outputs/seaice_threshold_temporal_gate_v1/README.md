# 年次衛星海氷とアデリー巣数の時空間照合：60–80%境界の歴史的識別性

本解析は、将来曝露シナリオで使う仮の60–80%境界を**過去の生物観測で検証できるか**の可否検定。
境界が実際に存在する前提は置かず、2041–2100年の繁殖数・生存・定着確率を算出しない。

- 原入力：39地点の凍結長期繁殖傾き、1991–2020年OSI SAF月次SIC、同種同地点のMAPPPD元計数法記録、元計数月監査の4 Git blob SHA。
- 30年平均の地点分類と地域の多数派による分類を比較。候補60–80%を0.1ポイント刻みで動かして、長期の「成長率の符号」に合う地点数が実際にどれほど変わるかを数値化。
- **同じ30年平均SICと年ごとのSICは別物。** 39地点×30年の8–11月SICを実測年に再構成し、年ごとの60–80%に入る観測、同じ方法で巣数が正の隣接年、厳密に両年とも11月後の計数確認ができた部分を別々に記録する。
- 仮閾値に下向き／上向きへ変化した年を数え、同じサイト・共有海氷画素での反復は独立実験扱いしない。3年以上継続する低SIC環境と一時的な越境を別の状態として計算。
- 月確認された隣接年巣数増減を、過去の観測年のみで学習した地点平均モデルと、同じ地点平均＋閾値以下の年を示す二値SIC条件（固定リッジ5）で時間順比較。これは当年の観測海氷が与えられた条件付き過去検証であり、将来巣数予報ではない。
- 生物学的境界の確証を受けずに閾値を「選択」することを禁止。既存Paper 1/2/mainと今までのCMIP6条件付き物理曝露は保存する。
