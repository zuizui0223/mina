# 海氷率60〜80%の境界はアデリーペンギンの繁殖変化を識別するか？（2026-11-01）

**判定：歴史的な空間・時間の観測から生物学的境界の同定はできなかった。** 物理的な海氷曝露の範囲シナリオは維持するが、60–80%を危険率や減少率に変換しない。

## 1. 30年平均の地点と年ごとの観測を分離

- MAPPPD固定源（1991〜2020年）からアデリー39地点の同一調査法・長期巣数傾向を使用。傾きは負14、非負25。
- 観測OSI SAF近岸（8〜11月、0〜100 km）の**39地点×30年＝1,170地点・年**を原月次9,600行から再集計。同じ繁殖地点の30年平均ではYALOが60.314%、その次に高い値はCRZEの80.429%で、**30年平均の60.314〜80.429%の間には繁殖地点がない**。
- しかし同じ海氷系列の**年ごとのSICは139地点・年が60〜80%**にある。この139は環境の反復観測であり、独立した139繁殖地ではない。現地計数と同年に対応する年もある。
- 平均海氷率77.5%を使って長期成長率の正負を分類すると **34/39（87.18%）**が一致。しかし5地域の中で長期成長の多数派の符号を当てるだけでも **34/39**。この比較は**学習標本内の記述的分類**であり、真の生物学的閾値の外部予測精度ではない。閾値65〜80%では分類結果が同じなので77.5%は識別されない。

## 2. 同じ地点・方法の年次巣数変化を実測で照合

凍結された各長期地点系列の計数方法だけを利用し、1991〜2020年の**478地点×季の実計数**から、2季連続し両季の巣数が正の**296隣接年区間／32地点**を構成。月情報をゼロや標準月で埋めず、元出典で**両年とも11月より後に計数されたことが確認できた191区間**を厳格な季節対応集合とした。

| 支持指標 | 件数 |
|---|---:|
| 39地点の30年分の年次SIC | 1,170地点・年 |
| 年次SICが60〜80% | 139地点・年 |
| 前年のSICが60〜80%で、実際の年次計数増減を計算できた | 43区間 |
| 上記で両年の計数が11月以降と出典で確認された | 34区間 |
| 77.5%を上から下に越えた年次計数区間 | 9区間 |
| 同じ下向き越境のうち計数月確認済み | **8区間・3地点コード** |

77.5%で下向き越境が確認された8区間の**7区間は巣数増減が正**、年次の平均対数増減は **+0.307**。上向き越境は出典月支持8区間で、平均対数増減 **−0.053**。この少数の歴史事例は「短期に境界を下回るとすぐ巣数が減少する」という単純解釈を支持しない。ただし同一年の共通海氷画素・個体群・年効果への依存が強く、低海氷の長期的影響が存在しないという検定ではない。

**特にCape Crozier**：元のCRZEとCRZWでは、1991〜2020年に77.5%を下回った年は各3年だが、いずれも**最長連続1年**。これは将来20年間の海氷平均が境界を下回るというシナリオと同じ観測状態ではない。

## 3. 過去の年だけで翌年の巣数増減を予測できるか

元の出典月を確認した191区間から、より前の年に少なくとも30区間・5地点の学習支持があり、テスト地点に過去2回以上の記録がある区間のみを使用。結果、**146区間・12地点**が時間順の評価対象になった。ただし**12地点すべてVictoria Land**。環境入力はテスト年の実測SICであり、真の将来の事前気候予報ではなく*条件付きhindcast*。

モデルは「地点ごとの過去の平均対数巣数増減」と、それに「年次SICが仮閾値未満である指標」を訓練データだけで学習した係数で追加する固定リッジモデル（penalty=5）。対象を変えずに比較。

| 固定の仮SIC閾値 | 地点過去平均 MAE | ＋低SIC指標 MAE |
|---|---:|---:|
| 60/65/70% | 0.21934 | 0.21934 |
| 74.4/75% | 0.21934 | 0.21659 |
| 77.5% | 0.21934 | **0.21536** |
| 79.8% | 0.21934 | 0.22053 |
| 80% | 0.21934 | 0.22131 |

77.5%だけを見ると改善は **0.00398 log単位のMAE／約1.81%** だが、201閾値の事後探索による最良値として採用しない。学習期間を固定し、**CRZE/CRZWの2コードを学習・評価の両方から外して同じ77.5%で再訓練**すると、**94区間・10地点**で基準MAE **0.23207**→低SIC指標追加 **0.23187**（改善わずか0.00020、約0.08%）。全39地点中の広域地域間転移を検証できていない。最初の191区間の月確証データもVictoria Land187、南極半島中西部3、South Shetland1という強い地理偏りを持つ。

## 4. 温暖化シナリオと論文での意味

**将来海氷の境界越えは実際の繁殖数の減少ではない。** 仮の閾値60〜80%による曝露の広域割合は、既存のCMIP6シナリオと固定カウントから計算できる。だが以下はまだ成立しない：

- 77.5%が種の真の繁殖適否転換点であるという断定
- 過去の年々の低SIC状態の係数を、将来20年平均の持続的なSIC低下へ直接移植する操作
- Cape Crozierが確実に減少する／ロス海の大繁殖地が絶滅するという人口学的予測
- サイトの増減サインを用いた地域の境界同定（地域構成と平均SICが強く重なる）

**成立する生態学的知見：** 島・地域間の長期SIC平均との差に見える地理的境界は、個体群が年々経験する海氷の変動範囲とは一致しない。環境境界の生物学的な可搬性が同定されない場合も、巨大小集団の現在の規模分布と将来の物理的曝露を重ねた**範囲シナリオ**は記述的に示せる。これ以上を生物応答として語らない。
