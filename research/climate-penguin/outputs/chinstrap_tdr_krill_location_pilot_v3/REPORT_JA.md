# BASヒゲ4タグ：暫定潜水圧力イベント → 元GPS時刻 → 既存オキアミGAM位置

2026-10-31、**パイロット・source-first QA**。前回TDRセンサから300の非空GPS/TDR対応を確認、4つの島から1追跡ずつ元圧力を開封し、暫定ゼロ点の4方式×2/5/10dbar=48条件を固定検証済み。

今回は固定した4タグ LIC001（Laurie）、PI001/TDR PIC001（Powell）、MIC001（Monroe）、SIC004（Signy）について、原時刻で対応できる「潜水候補」の元GPS位置を、出版済みFreer 2025年次モデル化オキアミラスターへ重ねる。**実潜水位置・捕食・餌へのアクセス量を証明するものではない**。

方法：2026-10-31に固定した source q1/60分、q1/30分、q5/60分、全期間q1のゼロ点補正、2/5/10dbar閾値、継続10秒、最大データギャップ3秒。GPSは元の前後実測10分以内、最近GPS点5分以内に限る。島別の基準位置は元308GPS追跡の最初の位置の中央値から決め、環境値・潜水結果に依存させない。緯度経度の距離10–150km内、GPS孤立速度スパイクを除き、重複する元GAMセルをタグ単位で一度だけ数える。元GPS全体を同じ距離/モデル年で要約した比較値を報告する。ただしGPS全体の追跡時間/位置選択と潜水候補が一致する保証はなく、生態効果・p値は推定しない。

元圧力センサは海面基準未検証で、Monroeの暫定ゼロ点幅7.75dbar、既存4手法による5dbar潜水候補の数が1254–1456（GPS厳格時間一致846–1012）。海氷・塩分の学習済みGAMとTDRの対応から独立な気候効果や将来繁殖数予測を結論しない。島の間で4タグ各1個体、かつ年が異なるため島効果を推定できない。

この工程の成功条件は元GPS・TDR・ラスターの再取得、原ID対応、48全条件の各タグの5dbar主数値、元セル・除外数・時間結合を再現できることだけ。確認できたら、個体のセンサ校正と潜水時の海域/陸域、採餌判別の次ゲートへ進む。**潜水候補=オキアミ捕獲ではない。**

実装: \`work/climate_penguin/chinstrap_tdr_krill_location_pilot_v3.py\`。GitHub Actionsで出典に戻れるCSV・決定JSON・全条件を成果物として保存し、凍結Paper1/2と既存216比較は不変。
