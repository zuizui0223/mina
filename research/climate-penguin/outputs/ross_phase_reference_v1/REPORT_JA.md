# Ross海の既報加工データにおける往路期・帰路期の対応比較

2026-10-30。既報の加工済み海氷移動補助指数を、同一個体・年の季節間で記述比較した。独立な追跡による新規検証ではない。

## 入力と比較単位

[著者公開Zenodoデータ](https://doi.org/10.5281/zenodo.8374474)の `IceSupportDF_envinddatana.RData`（CC BY 4.0）。原本MD5は19698ff037399b57f41572856ae98c55で公開値と一致。5,611行、146個体年、87個体、Crozier・Roydsの2繁殖地。元のRDataをRで再読込・CSV出力し、保存済み解析表の全列と照合した。

`yearweek`の14–22週と36–43週を早期・後期窓とし、各個体年内で`support5day`を平均して後期−早期を計算。15–21週／37–42週も感度比較した。これは概ね往路期・帰路期に対応する季節窓であり、個体の出発・到着日で区切った行動分類ではない。少なくとも1記録／3記録を各期に持つ条件を両方保存した。

## 結果

広い窓では139個体年・85個体が両期に対応した。未対応7個体年は欠測として表に保持した。

| 集計 | 後期−早期の平均指数差 |
|---|---:|
| 全139個体年 | −0.01982 |
| 個体ごとに年平均した85個体の等重み平均 | −0.01984 |
| Crozier：95個体年 | −0.02518 |
| Royds：44個体年 | −0.00822 |
| 2017：51個体年 | −0.02065 |
| 2018：50個体年 | −0.01850 |
| 2019：38個体年 | −0.02043 |

139個体年中107で後期の値が小さかった。早期平均自体も−0.01021、後期平均−0.03003であり、「往路は常に補助、帰路は常に障害」とは言えない。内側窓の平均差は−0.03011（139個体年）、各期3記録以上では−0.03026（138個体年）。元指数の尺度を保持し、ここでは単位を独立に確認できていないため速度へ換算しない。

## 何が検証できたか

単純な対応平均では、季節差の方向が両繁殖地・3年と窓の変更で共通した。これは既報の季節非対称性を点検する参照結果であり、未踏の発見、有意性検定、原論文の階層モデルの再現ではない。

著者コードの指数は実際の鳥の移動方向を計算に含む。独立な海氷曝露として繁殖時期や移動速度の原因にできない。原表には日別緯度経度がなく、新しい流動製品との独立照合もできない。回収された標識の対象選択があり、生存率・繁殖数変化や南極全域への一般化には使わない。個体年を独立個体として扱わず、個体等重みの結果も保持した。

公開資料の追加探索では、帰路の潜水行動の期間集計は取得可能だが位置がない。新規の海氷域帰路軌跡は確認できていない。[追加調査](../return_tracking_refresh_v1/PRIMARY_SOURCES_JA.md)。従って、機構の独立検証という未解決条件は維持する。

## 再現

`ross_processed_phase_reference.py --source <原表CSV>`で作成し、`validate_ross_reference.py --reexport <RDataから再出力したCSV>`で全表と個体年別各期の平均・記録数を独立照合する。両スクリプトは `research/climate-penguin/work/scenario_support_v1/` にある。全窓・最低記録数・地点・年集計をsummary.csv、欠測を含む対応表をtrip_phase_pairs.csvへ保存した。
