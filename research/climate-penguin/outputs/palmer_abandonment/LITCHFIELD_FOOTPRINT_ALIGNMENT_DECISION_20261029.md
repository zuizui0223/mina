# Litchfield旧営巣地の原図復元と、既存衛星観測点の位置ずれ

2026-10-29。原資料の取得・地図照合を実行済み。植生変化や温暖化の因果効果を推定した結果ではない。対象はdraft PR #206。凍結済みPaper1 #189、Paper2 #199、JNCC #201は変更していない。

## 新しく確認できたこと

2009年2月6日発行のERA / US Antarctic Program Map 7には、Litchfieldの「Former penguin colony」が10個の小さな輪郭として描かれている。原PDFを取得・描画して凡例と対応を確認し、ハッチング線ではなく閉じた輪郭を抽出した。経緯線15交点と原図記載のLambert正角円錐投影から地理座標付き候補図形を復元した。

**以前使ったMAPPPD登録座標周囲の25観測点は、この原図に描かれた旧営巣地を測っていなかった。**

| 原図との位置照合 | 結果 |
|---|---:|
| MAPPPD LITC登録点から最寄りの旧営巣地輪郭まで | 287.81 m |
| 既存25観測点のうち輪郭内に入る点 | 0 / 25 |
| 25観測点から輪郭までの最短距離 | 187.89 m |
| 2007/2008年NDVI比較に使った7点のうち輪郭内に入る点 | 0 / 7 |
| その7点から輪郭までの最短距離 | 200.31 m |
| 元の±80 m観測格子全体と輪郭の重複面積 | 0 m² |

したがって既報のΔNDVI中央値−0.1437は登録座標近傍の分光差として保持するが、「放棄された営巣地で植生が減った」「放棄後緑化がなかった」「仮説を棄却した」とは扱わない。今回の輪郭上で新しい反射率やNDVIは開いておらず、有利な符号が出るまで観測位置を動かした解析ではない。

## 復元データの用途と限界

原図の図形面積は1個あたり9.68–114.97 m²、合計500.77 m²。個々の図形は30 m Landsat画素の名目面積900 m²より小さい。ただし、これは地図に描かれた図形の大きさであり、過去の真の営巣面積を新たに測量した結果ではない。原図の鳥類情報はW. Fraser（2001–2009）に帰属するが、各輪郭の観測年と9つのセンサス区画コードとの対応は不明。10図形を10繁殖地・10独立反復と数えない。2009年の発行日を一律の調査年や放棄年に置き換えない。

用途は、旧営巣地を狙うための**暫定的な地図由来候補マスク**と、登録座標を営巣地そのものとしていた代理測定の診断である。原オルソ画像または現地測量による位置検証、年代付き占有境界、対照区、センサスコードの照合は未完了。海獣の踏圧や融雪の交絡も今回取り除いていない。

経緯線への当てはめRMSEは0.139 m、交点を1つずつ外した最大誤差は0.221 m。ただし、これらは地図内部の整合性であり**現地での絶対位置精度ではない**。原図はWGS84楕円体上のUSGS LIT1ローカル測地基準を記載しており、WGS84地理座標との差は未解決。別の経緯度線形補間でも登録点の復元位置は0.022 m以内で一致したが、これも計算の確認に限る。距離は原図に条件付いた診断値として報告する。
