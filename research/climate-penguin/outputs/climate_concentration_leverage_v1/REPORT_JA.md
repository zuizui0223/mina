# Breeding-space concentration and local climate: scale-specific sensitivity (2026-10-31)

**主線**：「個体群減少 → 繁殖区画への集中」は観測的に支持されている。これが「残存区画の局所海氷で個体群全体の運命が決まる」へ接続するかは、**島・区画間の実際の海氷差と環境ショックの相関**で決まる。現在のCMIP6格子では同じ小島内の区画差を識別できない。

## 数学的に導かれる（因果係数なし）

観測した繁殖ペア比率を`p_i`、各区画に作用する短期的な外部ショックを`z_i`とする。ショックの分散が共通`σ²`、区画間の共通相関を`ρ∈[0,1]`と**仮定**した場合、加重ショック平均の分散は

`Var(sum p_i z_i) / σ² = ρ + (1-ρ) sum(p_i²) = ρ+(1-ρ)/N_eff`。

したがって**N_effが小さくなると分散が増すのは、ショックに独立な局所成分がある場合のみ**。`ρ=1`（島内全区画が同じ海氷ショック）では**増幅は常に1倍**。式は外部ショックの瞬間的な加重曝露の分散で、繁殖ペア増減・将来気候・因果的選択の分散を実測したものではない。

## Palmer原センサスの実行結果

元センサスの凍結SHA256：`b4ef04e2275ea779fc8fe54fa13528dc2052d37dd88a60c811d54c7601f67b16`。2026年9月の出典原本を[Palmer GitHub Actions run #36292092967](https://github.com/zuizui0223/mina/actions/runs/36292092967)、[結果原本](https://github.com/zuizui0223/mina/blob/main/results/PALMER_BREEDING_PATCH_CONCENTRATION_RESULT_V1.json)へ照合。年は1991と2017を事前に決めていた本研究の端点であり、結果に合わせて選び直していない。

| 指標 | 1991 | 2017 | 独立ショックと仮定した加重曝露分散の倍率 |
|---|---:|---:|---:|
| 5島のセンサス繁殖ペア数 | 6,689 | 140 | — |
| 5島間の実効島数 | 3.449 | 3.079 | **1.12倍** |
| 5島の監視繁殖区画を統合した実効区画数 | 31.056 | 6.148 | **5.05倍** |

これは実測の繁殖数配置から導いた**仮定付き分散感度**。島ごとのローカルショックと区画ごとの独立ショックでは増幅上限に大きな差がある。末期2017年の計数は合計140ペアで、有限サンプル・同じ`colony_code`のGIS形状連続性などの感度を保持する。上表の広域`N_eff`は既報の「島内`N_eff`」とは違う統合指標。

## なぜ島内集中から局所「海氷」効果を即断できないか

**重要な等式**：島内すべての繁殖区画が同じ年・島の海氷曝露`SIC_i`を共有するなら`sum_c p_(c|i) SIC_i = SIC_i`。したがって、島内の繁殖区画数`N_eff`が下がっても、島単位の海氷曝露の加重平均は変わらない。

さらに、既存CMIP6のLITC・BISC・DAMO・PCHAの**異なる4つの研究座標**を照合すると、全4将来条件で同じ3モデル海洋グリッド組合せ `F018` を共有し、海氷濃度変化は数値上まったく同じ。これは現地の海氷が同じだった実測ではなく、CMIP6がこの近隣スケールの差を分解できないとの証拠。

**この研究の科学的に検証可能な核心は**「局所ショックの空間共分散が、島内区画・島間・地域間のどの階層に存在するかに応じて、繁殖区画集中の増幅効果が異なる」というもの。

## 今後の判定

1. 残存区画の年次繁殖割合・同位置GISポリゴンを取得。未検証のコードを実面積に直結させない。
2. 年次海氷の島間差・各島の本当の採餌経路（GPS）と局所海氷・餌場の同時時刻を対応させる。海氷をコロニー独立のショックと仮定しない。
3. 地域平均の変動と`SIC_island-year − SIC_region-year`を分離し、`N_eff`を交互作用・分散構造に入れる。年・島のホールドアウトで追加予測情報を確認する。
4. 雪・融雪・海岸地形・局所餌アクセスも、区画間で本当に差があるかを実測する。その差だけが区画集中の直接的な脆弱性となり得る。

**NO-GO**：現在は海氷ショックの空間共分散・区画別GIS・海氷から成長への効果が未較正。したがって温暖化による将来の巣数、地域絶滅、緑化や将来N_effの点予測は出していない。
