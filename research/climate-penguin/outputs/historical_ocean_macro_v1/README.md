# 40 macro breeding sites → 34 marine support points → source-first GLORYS 1993–2020

The earlier co-observed three-species ratio analysis covered 8 sites with 13
species comparisons. This cohort **does not replace it**: it expands the original
40-site MAPPPD geography, keeping every site whose original fixed 2011 marine
grid is ≤25 km away. The original 6 Ross Sea source sites beyond that distance
remain missing, never imputed.

On the frozen source spatial atlas: 40 original biological sites, **34 near-grid sites**.
The 34 biological sites are NOT assumed to map to 34 independent native marine
cells. The original GLORYS grid IDs are retained, distinct cells are counted.

This pipeline extracts GLORYS12V1 v202311 August–November 1993–2020,
uses the original top ~0.494 m, and checks *all* 2011–2020 overlapping model
values against the pinned existing model file (34 × 40 = 1360 site-months).
The historical source is modeled/reanalysed salinity and potential temperature,
not an independent satellite instrument.

Once the 34-site original source checksum is confirmed, an independent
source-backed three-species growth panel and chronological/site-out macro
hindcast can be compared against same-method counts. Do not select successful
sites/variables based on outcome coefficients.

Main, frozen Papers 1/2 and 8-site evidence remain unchanged.
