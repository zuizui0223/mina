# Signy島3種のオリジナルGPS採餌追跡ファイル：原資料の取得監査

2026-10-30。*生態学的出力と独立したソース監査*。海氷・塩分・オキアミモデルと繁殖成功の実測接続で残った「島から実際に到達した餌場が不明」という障壁を解消するため、BASの**公開GPSデータ原ZIP**を直接確認する。

原公開元：
- [アデリー2011–2016 GPS](https://doi.org/10.5285/55b4d36f-c5e1-4d64-bb14-0b832dcd4b88) — Signy。メタデータ上では数繁殖季のタグであって全期間均一ではない。
- [ヒゲ2011–2019 GPS Version 2.0](https://doi.org/10.5285/8f8ccba5-01af-4b00-8a3b-c3c85b24bf92) — SignyのほかLaurie, Monroe, Powellを含む。Signy個体へ厳格に絞る必要がある。
- [ジェンツー2011–2016 GPS](https://doi.org/10.5285/9cb04ca6-f88f-4368-b715-45ff73ff81eb) — Signy。メタデータ上の装着個体数は非常に少ない。

Version 2を使用するのは先行Version1にGPS/TDRの照合不整合が報告されているため。GPSは動物の位置であり、採餌・潜水・捕食成功の直接観察ではない。元メタデータの署名、雛段階・胃内容物の撮影/採集時期を別に照合する。

本gateではCSV原ファイルごとのSHA256・ヘッダ・行数・Signyラベルに関する候補数のみ取得する。**原GPS座標や移動距離の数値を読んで効果を合わせる前に**、位置列とdeployment keyを確定し、位置ノイズ・上陸行動・タグ別非独立・地理的格子の複製を扱う次gateを設計する。

次gateで初めて、GPSの海上有効位置から鳥個体×年ごとの利用カーネルを構成し、2011–2020年のFreer元GAM年次krill予測ラスタを標本地点へ抽出。島中心25/50/100kmの恣意的円と比較する。ただしFreer GAMは**元IMR音響と海氷・塩分を既に含む**ため、これだけで海氷→餌の因果効果・外部検証にはならない。3種の雛数・繁殖空間との接続は、独立した年/地域の検証が可能か判定してから行う。

元データの再配布なし。原ZIPをGitHub Actionsで取得、再現可能な構造監査をartifactに保存。Paper1/PR189とPaper2/PR199、既存216比較の補正、将来繁殖巣数の推定禁止は不変。
