# 温暖化 → 観測巣数リスク → 保護区：事前固定 v1（2026-11-16）

**状態:** 方針固定＋ソース版ゲート。これは新たな独立野外研究の事前登録ではなく、先行探索結果を見た後の確認的再解析仕様。単一 Antarctic macro draft PR #214 上の補助計画で、既存の v0.5 論文・主図4枚を勝手に上書きしない。

## 0. まずソース母集団と「用量反応」の推論を分ける（必須PASS）

今回提示された「1980–2000 と 2005–2025 で272系列／環境結合265系列、ADPE 102・CHPE 116・GEPE 47」は**新しい版の候補値であり、元ZIP・site ID・集計スクリプト・ダイジェストがまだ照合されていない**。元 mina 固定ソース（MAPPPD系、原2456 site×species×year、595記録サイト、固定最頻計数方法）で同じ期間の各1件以上条件を独立計算すると **159 site×species**。272・265との出典/版/フィルター差が確定するまで、その系の β や予測リスクを数値的に追認しない。最新版MAPPPD v5.0（2026-10-21、全6種/5,487カウント/729 count-bearing sites）の元source ID、年・方法・種ID、基準計数単位をダイジェスト固定し、3種だけを抽出して要求系列の実行を再現する。データの重複/欠測/異なる方法に失敗したら**STOP_SOURCE_UNVERIFIED**。

## 1. 凍結比較単位と時期

- 応答：source site×speciesごと、真の実計数年1980–2000の中央値 `n_early`、2005–2025の中央値 `n_late`。最低各1実測年を「探索母集団」として記録し、**確認比較は各期間2年以上**と別に示す。測定した0は0として保持、未観測年・種はゼロに変えない。観測後期情報を前期近隣説明変数に絶対に使わない。
- 応答率は `10 * (log1p(n_late) - log1p(n_early))/(median_year_late-median_year_early)` （10年当たり）とし、年差>0、極端な増加は事後的に削除しない。地点×種の元調査方法・元出典期間・観測数・重複を記録。初期個体数との算術的回帰平均効果を分けるため、初期巣数 `log1p(n_early)` を共変量に入れる。
- 母集団目録は**同じスナップショットの全既知コロニー**、近隣圧力は**初期1980–2000に実際の同種計数がある目録地点**からのみ構成する。後期だけ観測された隣接コロニーや全目録の未観測は「生息しない」とはしない。
- 近隣指標：元WGS84緯度経度の測地線距離、同じsite IDを除外。半径 `10,25,50,100 km` を**結果を見る前に固定**。50kmが*探索仮説の主半径*、10/25/100kmは等しく報告する固定感度。各半径の早期実測同種コロニー数、正の巣数中央値の合計、log1pその合計、早期zeroの件数、初期時期未観測の目録サイト数を保持。初期観測のない近傍はunknownであり、0巣としない。最寄り同種繁殖地点距離が未観測ならNA（無限遠や最大半径に丸めない）。
- 空間支持：元site ID、報告地域、EPSG:3031原250kmブロックの3階層。必ず重複サイト・同一海洋格子の多重計数を記載。反復年を独立siteとして複数回数えない。

## 2. モデルと判定（予測の正負を見てから変更しない）

- 係数は**region×species fixed effects**を保った `decadal_log_change ~ log1p(n_early) + log1p(observed_conspecific_nests_50km) + log1p(early_nearest_distance_km)`、各地点×種1票。近隣観測ゼロと近隣未観測は分け、距離欠損は**モデルからその行を除いて分母を報告**。地域×種支持が不足すれば明示的NO-GO。各半径の線形相関も全て記録し、主張対象は50kmだけ。
- 250km空間ブロックを**復元抽出**する固定シード20261116・2,000回感度。CIと称する前に有効独立ブロック数／地域・種支持／再標本化でのフルランク率を報告。四半径から都合のよい一つを選んで有意性と呼ばない。source-cohortが新しい265と違う場合、その結果は「旧159系列パイロット」であって新265の検証ではない。
- 環境係数は「**長期巣数変化 ~ 1993–2020年の地点平均 Marine-PC1 + region×species + early-size + survey-support**」を前述の同一生物母集団上で再推定。モデルの地域内環境PC1分散が小さい／地域固定後の係数が消える場合は **REGION_CONFOUNDED_NO_TEMPORAL_TRANSFER** と判定。**地域間の現代気候平均の回帰係数を将来の同一地点の温暖化量に掛けない。** 元265提示のADPE −0.80 [−1.49,−0.41]は地域間探索推定として隔離する。
- 気候×近隣交互作用は一つの固定 `PC1 × pressure_50km` 比較のみ。帰無の残差や候補半径を見て仕様変更しない。地域間不均質性を同時に検証し、地域を無視した正の結果だけを主結果にしない。
- 先行研究の用量反応の存在確認と「別の初期母集団」での再現を確認的ステップとする。現行の地域間相関は「暖かい状態の場所ほど減った」という地理的記述であり「未来に暖かくすると必ず減る」という時間因果関係ではない。

## 3. 将来曝露（温暖化影響の**物理シナリオ**であり、巣数予測ではない）

- 3つの既存CMIP6元モデル（ACCESS-CM2 / BCC-CSM2-MR / CESM2）× SSP2-4.5・SSP5-8.5 × 2041–2060・2081–2100。**source model / member / calendar months (Aug–Nov) / historical baseline / lat-long wet cell and distanceを保持**。歴史モデル基準と観測の平均は直接合算しない。海洋温度と海氷の未来差は別々に出し、将来の塩分がない限り完全な物理PC1を再構成したと主張しない。旧コホートに基づくCMIP6ソースは全595／新265のカバレッジを満たさないなら **STOP_SCENARIO_COVERAGE** とする。
- リスクの分母は**コロニー数でなく調査済み原巣数中央値の合計**（ペア数の近似で、個体数そのものではない）。事前に選んだ2011–2020の真の調査巣数中央値を初期重みとし、0と未調査を区別。計数methodと実測年数の条件をロスター固定、地点を変えず同一母集団で比較。変化の平均 `Σ(n_i * ΔSIC_i)/Σn_i` をコロニー等重み平均と対照し、正の巣数重みがCMIP6の wet-cell/dist品質ゲートを通った割合を**必ず一緒に報告**。ユーザー提示の−10.1pp/−2.2ppはsource再現前の参照値として保持し、未確認の数値を新しい結果として報告しない。
- 分布：model×SSP×period×species×source region別、source wet-cell重複除去との感度、元巣数重みトップコロニーの感度と地理的集中度を出す。物理 `ΔSIC` と `ΔT` の原native単位の曝露だけを提示し、**−0.80×将来PC1 を将来巣数予測にしない**。

## 4. 保護区の空間判定は陸・海を混ぜない

- 公式のCCAMLR採択済み海洋MPAの**法定 zone polygon と conservation measure 適用年、漁業制限zone**を保持（[公式 CCAMLR MPA](https://www.ccamlr.org/en/science/marine-protected-areas-mpas)、[CCAMLR GIS](https://spatial.ccamlr.org/)）。南極条約の陸域ASPA/ASMAは別の管理制度・別レイヤー（[Antarctic Treaty protected areas](https://data.aad.gov.au/metadata/records/AAS_4296_Updated_ASPAs_2024)）。候補・提案中MPAは採択済み保護区として数えない。
- 陸上の営巣site点が海洋MPA内にある／ないという幾何判定は**採餌域の保護を示さない**。観測可能な追跡データがない場合は、固定50/100/200kmの海上潜在アクセス円と実際の保護区marine zoneの重なり面積（観測採餌域ではない）を別々に報告。形状・法的管理・適用年が検証不能なら **NO_GO_PROTECTION_COVERAGE**。オキアミ漁業との競合は追加の正式漁獲努力・年×季節がない限り未解析。
- 実際の保護状態と温暖化によるリスクは別軸。『避難地』は現地の繁殖生残・採餌適性を検証していないので**候補環境帯**とだけ表記し、個体群維持確率としない。

## 5. 自動的に出す判定とSTOP

必ず`source_gate.json`, `original_early_late_cohort.csv`, `conspecific_neighborhood_10_25_50_100km.csv`, `physical_exposure_coverage.json`, `risk_gate_verdict.json`を保存。各出力に original source paths / SHA256 / run ID / source-site denominator / count-weight denominator、欠損/除外理由を付す。**265系列再現に失敗、region-centering後に係数不安定、観測巣数とCMIP6 source重み支持不足、MPA polygon未取得のときは、該当項目だけNO-GOを出して止める。** 別の解析で空いた欄を捏造して埋めない。

メタ解析は後で別契約にする。今回の目標はまず**真正ソースの一致と、将来の環境物理曝露（非生物予測）を支持分母付きで実測から出すこと**。
