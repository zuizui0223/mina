# Common survey-year confounding diagnostic on original dual-axis penguin co-censuses

**2026-11-11, after exploratory dual-PC result was examined.** Explicitly post-result, NOT independent temporal confirmation or a new preregistered test. Single follow-up to Draft PR #214's 18-region Antarctic marine 588-colony 28-year macro paper, no new environmental data or manuscript branch.

Observed before this diagnostic:
- The actual source fixed 588-site 1993–2020 physical PCA PC1 explained 60.37%, PC2 (almost salinity) 33.38%. Source reconstructed exactly in run #42969734584.
- Actual same-colony same-season both-species nest records 98 ADPE/GEPE, 165 CHPE/GEPE, 88 ADPE/CHPE. Only the CHPE/GEPE original source gave weak consistently negative salt-PC2 *site-demeaned* response: equal-site two-PC coefficient PC2 −0.187, excluding source recorded zero counts −0.137. In-sample two-PC site-demeaned response variance fraction ≈2.1%, i.e., tiny.
- Effect attribution still unknown: the local salinity score and nest ratio may both respond to year-wide conditions or site-year sampling, instead of to an independent physical salinity constraint.

## Frozen diagnostic, do not optimize
1. Reuse immutable output artifact of successful run #42969734584, all 351 original same-site same-year true source-count ratios and original full-source standardized PC1 (warm/low-ice), PC2 (salinity), all source real zero flags, polar 250km block, region, year and original source count-method gate. No new selection threshold, offset or predictor.
2. For **all THREE originally fixed species pairs**, compare the already computed within-site equal-site two-PC regression to a weighted **site-and-calendar-year fixed effects** model fitted on the exact same genuinely repeatedly co-counted source colonies (>=2 real pair years per site). Per-colony equal total weight 1, preserve actual sampled years with no padding; year fixed effects remove a shared same-calendar-year component across sampled colonies.
3. Calculate two-way fixed effects by weighted FWL projection: nuisance columns consist of every original site dummy, plus one dummy per observed calendar year except a fixed first year. Residualize both original climate PC scores and actual log1p nest count ratio with exactly the same weighted nuisance design. Fit two concurrent PCs on the remaining weighted actual observations, requiring rank2 and effective residual degrees of freedom >=5. Report original sites, observed years, source geographic regions/blocks, nuisance rank, effective year support (number of calendar years with >=2 sites observed), matrix condition, coefficient signs and descriptive within-sample residual R2. No p-values (spatially non-independent panels and post-selection).
4. Repeat on exactly the same original rows after excluding genuine observed 0-nest records for either species. The original source row is not deleted from other evidence; exclusion is a sensitivity, not biological pseudoabsence.
5. Guard against disconnected site×year source components and year FE overfitting: report effective residual degrees of freedom and number of separate bipartite site-year connected components (a graph component with only one source site has no within-year cross-site information). A year effect can remove genuine shared ecological climate change; the two-way model is **not the uniquely correct causal estimator**.
6. Label output as: if salt PC2 coefficient sign survives site+year FWL, it is only an exploratory residual association, **not causal salinity niche selection**; if sign disappears/changes, original weak salt association is sensitive to common time. Neither outcome authorizes a future biological forecast or 18-region 2-species replacement claim.

One source-verified output for all three species, source-year and real-zero sensitivity, and explicit note on whether the small earlier CHPE/GEPE PC2 signal is robust to calendar-year adjustment.
