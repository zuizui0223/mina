Original expected positive direction failed. A separate later-winter temporal placebo on **358 original site×seasons** gave more negative P0 than P1. The original Y is an **independent single full-sample sklearn PLSR5 per sensor**, with 100 train/test repetitions used only for lab CV. The published source code uses **R pls::plsr oscorespls; 1000 x 65% stratified training; ncomp6 fit and ncomp5 ensemble coefficients**. L7 author-style and novel L8 have been actually run on 103 lab isotope specimens, but were not yet applied to original old penguin pixels.

**Only intended sensitivity variable**: replace the original single-PLSR old optical Y on exactly the same old, already-selected `guano_bin=1,bad=0` RDS pixel rows with three original-sensor (L4 TM, L5 TM, L7 ETM) separate, original-author R 1000-fold five-component coefficient ensembles. Average the ensemble predicted optical δ15N across original old selected pixels within site×acquisition calendar day; average across observed days within site×breeding season **equally** (identical old 860-row procedure). No artificial 2013–21 new image Y; no new coordinates; no changing guano selector; no new original source pixels admitted.
