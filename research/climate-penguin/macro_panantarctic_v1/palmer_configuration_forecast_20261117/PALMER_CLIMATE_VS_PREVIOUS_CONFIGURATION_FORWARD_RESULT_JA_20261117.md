# Palmerアデリー5島の翌年巣数配分：前年配分と海氷を真正ソースで時系列外比較

**2026-11-17 JST｜mina Draft PR #214 補助検証。単一南極マクロ論文の候補要旨v0.6に付属。**

## 今回実際に新しく確かめたこと

**Palmer諸島の同じ5島で、翌年の繁殖ペア数の相対配分は、既知の前年配分によって海氷だけのモデルより精度よく予測された。** ただし、この比較は「前年の実測状態が高い自己相関をもつ」という予測情報を測っており、帰巣性・社会的定着・コロニー間移住の原因が判明したのではない。使用した海氷は近岸Litchfield 0–100kmの共通年値であり、5島で違う実際の採餌環境ではない。

Palmer LTER原資料に由来する固定5島（CHR/COR/HUM/LIT/TOR）の**1991–2017年・27年×5島=135島年**のAdélieペア数と、巣数調査前の**同年8–10月OSI SAF SIC**を結合。毎年5島すべてに実計数があり、Litchfieldの2007–2017年のゼロは本当のsource計数ゼロとして保存した。無観測年や種をゼロ補間しない。5島合計は1991年**6,689**、2017年**140**ペア。この島の元colony-code構成数はCHRが14→13、TORが17→16に変わっており、「同じ5島」であっても島内の調査区画の完全一致を保証しない。

## 評価の単位と手順

予測先：**2001–2017年17回、各年ひとつの5島全構成**。各テスト年 t について、t−1年までの巣数配分とSICで学習。調査より前に実測されるt年8–10月のSICを外部環境入力として許可し、t年の巣数は予測スコアを出すまで隠した。20年先の気候予報ではない。

すべてのモデルの5島の予測比率を和1・非負へ単体射影し、各年の全変動距離 TV = 0.5 Σ_i|予測巣数比率_i − 実測比率_i| を計算。年は**各1票**で平均し、同一年5島を5つの独立気候実験と扱わない。定義された7モデル、回帰時のridge傾き正則化λ=1、時期スケール10年、SICスケール20 pp、テスト起点2001年、固定3年連続年再標本化4,000回、固定seed20261117。データ結果を見てラグ・半径・正則化強度を探索的に変更していないが、研究全体は従来の探索を踏まえているので独立事前登録でもない。

- 過去年の平均配分：過去に見た全ての年の島別平均
- 年次トレンドのみ：過去年から学習した島別線形年次効果
- 海氷のみ：同年8–10月の地域SIC値から各島シェアを予測
- 年次トレンド＋海氷：二変数を入力
- **前年の配分**：前年に実測した5島の構成そのもの
- 前年の配分＋過去の平均変化：前年構成に、過去の年次シェア変化の平均を加える
- 前年配分＋海氷変化：過去のシェア変化〜SIC前年差から学習した補正を前年構成に加える

## 実測留保17年間の結果

| 予測情報 | 平均TV（低いほど正確） | 年内5島比率RMSEの年平均 |
|---|---:|---:|
| 過去年の平均配分 | 0.172607 | 0.084287 |
| 年次トレンドのみ | 0.099909 | 0.050870 |
| 海氷のみ | 0.165533 | 0.080917 |
| 年次トレンド＋海氷 | 0.099265 | 0.050133 |
| **前年の巣数配分のみ** | **0.055265** | **0.030006** |
| 前年配分＋過去の平均変化 | **0.054307** | **0.029206** |
| 前年配分＋海氷変化 | 0.054889 | 0.029586 |

海氷のみのTVから前年配分のみを引いた差は **+0.110268**（前年配分側が低誤差）。3年連続年を一つの単位として4,000回復元抽出した差の**条件付き2.5–97.5%点は[+0.060452,+0.150733]**。これは1地域の17年間を再標本化した感度であり南極全域の信頼区間ではない。

**気候を状態へ追加したときの限界：**
- 年次トレンド＋SIC − 年次トレンドだけ：**−0.000644 TV**、時間ブロック再標本化[−0.006827,+0.004178]。
- 前年配分＋SIC変化 − 前年配分＋過去平均変化：**+0.000581 TV**、同[−0.001509,+0.002146]。
- 前年配分＋SIC変化 − 前年配分のみ：**−0.000377 TV**、同[−0.002634,+0.002865]。

符号はいずれも安定せず、今回の8–10月地域平均SICを加えれば翌年5島の配分予測が向上するとは示されなかった。

## 二つの固定期間での感度

元Litchfield計数が真の0になる年を事前にsource変化として固定し、17テスト年を**2001–2006（6年）**と**2007–2017（11年）**へ分けた。前者のTVは海氷のみ0.088338・前年配分0.043542・前年＋SIC0.045845。後者は海氷のみ0.207640・前年配分0.061660・前年＋SIC0.059821。つまり前年配分が低誤差である方向は両側に見えるが、前期は6年しかなく新しい独立気候実験ではない。

テスト年を一つずつ除いても、海氷のみ−前年配分の平均TV差は**+0.101031〜+0.118829**。一方SICを前年配分＋平均変化に追加した増分の符号は**−0.000226〜+0.000980**へ変わる。未検証のモデル族・遠隔気候変数・局所環境へこれらの差を拡張しない。

## 論文の主張と境界

**肯定的かつ狭い結果：** 同じPalmerの5島で、実測された過去の繁殖地配分には翌年の相対配分に関する強い予測情報がある。これは「温暖化があっても鳥は移動しない」ではなく、**繁殖配置という状態変数が、単一地域の気候代理値より細かい島間情報を保持する**という、空間階層の比較である。

**否定ではなく識別不足：** 今回SICは全5島共通の一つの地域年系列で、氷・水温・塩分・食物・海への通路・雪の島間相対差は入力していない。このモデルでSICが予測を改善しないことは、気候の作用不存在、地域の巣数成長に対する影響不存在、他種の分散能力差を意味しない。さらに前年巣数シェアの予測優位は自己相関の強い配分に対して期待されやすいので、それだけではアリー効果、社会的ゲーム、帰巣性、競争、移住・出生死亡を識別しない。

**主原稿への配置：** 潜在機構を誇張せず、候補v0.6の第2層の補助的な独立時点チェックにとどめる。全南極の将来の繁殖地配分・絶滅率・2050/2100巣数には変換しない。南極マクロの従来の595地点/3種における2,456巣数観測や海洋二軸性をこの単一Palmer結果で置き換えない。
