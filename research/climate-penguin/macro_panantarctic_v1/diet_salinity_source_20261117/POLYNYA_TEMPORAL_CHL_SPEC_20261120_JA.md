2026-11-20。既存439地点季節の負の関連を受けた探索的追加解析。仕様作成時に新しい応答との関連は計算していない。独立確認研究・事前登録とは呼ばない。元の正方向仮説とその不支持判定は変更しない。本書は新規解析の仕様であり、実施済み結果ではない。

## 1. 問いと一次判定

冬の沿岸ポリニヤと直後の夏の光学δ15N proxyとの負の関連に、翌冬のポリニヤでは説明しきれない時間特異性があるか。

繁殖季開始年yについて、P0=同年6–10月、Y=同年11月〜翌年2月の元日等重み光学δ15N、P1=翌年6–10月。実画像日がP1より前であることを元画像日付で照合する。元439表の平均DOYだけから全画像の日付順を保証しない。元画像日付を確認できない場合、負の対照としての判定を保留する。

未来のP1が既に観測されたYを直接引き起こすことはない。ただしP0とP1の持続性、共通の海洋条件、測定誤差があるため、P1の関連は自動的に交絡だけを意味しない。通過も因果性の証明ではない。

## 3. モデルと時間特異性の判定

C0=元DOY、DOY²、同夏SIC・水温・塩分、元地点固定効果、元地域×季節固定効果。新しい調整変数やラグ選択はしない。全モデル同じ完全行を使う。

- Mnow: Y ~ C0 + P0
- Mlead: Y ~ C0 + P1
- 主モデル Mjoint: Y ~ C0 + P0 + P1

主対比はMjointのD=β(P0)−β(P1)。同じ10百分率ポイントの変化で表示し、別々に標準化した係数は比較しない。Dの分散は二係数の共分散を含めて計算する。元地域クラスタ分散、t(地域数−1)による両側95%区間を使用。地域一つずつ除外を全て報告する。単にP0が有意でP1が非有意という判定は禁止。

主解析前の識別診断：固定効果とC0を差し引いたP0/P1の相関、残差標準偏差、ランク、標準化した設計の条件数を保存する。ランク不足・変動消失、または残差相関の絶対値0.95以上なら時間の区別が困難として主対比の解釈を保留する。年を追加・削除して通過を狙わない。

探索的TIME_SPECIFICITY_SUPPORTEDは、β(P0)の95%区間上限<0、Dの95%区間上限<0、地域除外で両方の点推定が負、かつ識別・支持条件を満たす場合に限る。それ以外はTIME_SPECIFICITY_NOT_ESTABLISHEDまたはNOT_IDENTIFIABLE。後者二つは「関連が偽物」「無効果」を意味しない。Mnow/Mleadの係数・区間と標本変更による差も併記する。

指定条件を満たさなければ、今回の逐次計画ではクロロフィルとの応答モデルを実行しない。独立した別研究としての生産過程検証まで禁止する意味ではない。半径変更、追加ラグ、再閾値化はしない。実装不具合の修正と再実行は理由・差分を記録し、最初の出力を消さない。

## 4. 条件付き第二段階：クロロフィル経路整合性

ここで検証するのは「ポリニヤ→植物プランクトン→食物網の同位体」という説明に整合する関連があるかであり、因果媒介効果ではない。クロロフィル濃度は植物プランクトン現存量の指標であり、生産速度そのものではない。同夏平均は一部の画像より後の値を含むため、時間順の確立した媒介変数とは扱わない。

製品はOC-CCI v6.0、日別約4 kmのchlor_a（mg m−3）、同じ100 km測地圏、夏11〜2月。配布URL、バージョン、実取得ファイル・ハッシュ、品質情報、海域マスクを固定保存する。版やプロバイダを入手都合で置き換える場合は、Yとの関連を計算する前に変更記録を追加する。

元の有効値・品質基準を用い、欠測・陸・氷域をゼロにしない。固定海域分母に対し面積20%以上に有効な正のchlor_aがある日だけ日別面積重み平均を計算。各月5日以上、月の前半・後半に各1日以上、4か月全てを要求する。月平均→4か月等重み平均のlog10をCとする。閾値は運用上の事前基準で、代表性や検出力の保証ではない。観測率、最大連続欠測、品質・不確実性情報を保存する。

海色は別の観測情報だが、海氷・雲・太陽高度による可視性がP0やYの測定と関係し得るため、独立な誤差とは仮定しない。Cが取得できた行と欠けた行について、年・地域・P0・SIC・取得率を比較し、観測可能な開水域のクロロフィルであることを明記する。20%未満の被覆を別閾値で救済しない。

Yとの結合前に、少なくとも30地点・6地域・4季節と全共変量の支持を要求。元画像の季節/座標と海色の時間・空間対応を検証する。支持不足はNO_GO_CHL_SUPPORTとし、代替半径や月を探さない。

第二段階は時間対照を通過した共通標本のうち海色も揃った同一行で行う。新しいCの欠測に伴う係数変化と、C調整による係数変化を分けるため、Mjointをこの縮小標本で再推定してから比較する。

- 生産系関連: C ~ C0 + P0 + P1。P0の係数aを記録。
- 指標関連: Y ~ C0 + P0 + P1 + C。Cの係数b、P0の調整前後の係数、差Δβを記録。
- 仮説方向はa>0、b<0、調整前の負のP0係数が0に近づく。これらは今回検証する仮説で、既存研究がこの地域・季節で保証した符号ではない。

副解析として、a、b、a×b、Δβについて地域を単位とした4,999回のペア・ブートストラップ（seed=20261120）で区間を示す。重複抽出した地域の固定効果IDはコピーごとに分ける。推定不能反復数を報告し、有効反復90%未満なら区間による判定を保留する。a×bは関連経路の要約であり因果的間接効果とは呼ばない。地域数が少ないため区間の不安定性も明記する。

経路整合性の判定はaの区間下限>0、bの区間上限<0、Δβ（調整後−調整前）の区間下限>0、かつ調整後P0が負または0に近い方向である場合。これらを満たしても「生産系経路と整合」と書く。係数が変わらなければ「このクロロフィル測定では説明できなかった」であり、「食べ替えが有力」とは判定しない。元P0が0付近の場合は減衰率を計算しない。全解析を探索として併記し、独立な複数の確認成功と数えない。

## 5. 今回は凍結しない別解析

海氷との交互作用、50 kmの追加、距離勾配、翌季巣数はこの仕様の主判定に含めない。別途実施する場合は支持と仮説を先に定義する。25 kmで強い関連は近距離採餌でも起こり得るので画像アーティファクトの証明ではない。50–100 kmで強いことも採餌機構を特定しない。半径は入れ子で、海域面積・曝露分散も変わる。採餌距離と画像品質を直接照合する必要がある。

冬ポリニヤと翌季巣数の関連が出ても、雛の翌年加入とは説明しない。繁殖参加、生存、移入、調査差などを区別する必要がある。別の応答として価値がある一方、同じ気候交絡から独立とは限らない。

2013年以降の独立期間は、測定仕様と解析を固定し、結果を見ずに評価できて初めて時間外再現になる。「誰も見ていない」ことは確認できないため主張しない。元著者への連絡・返信状況は本仕様作成では確認していない。
