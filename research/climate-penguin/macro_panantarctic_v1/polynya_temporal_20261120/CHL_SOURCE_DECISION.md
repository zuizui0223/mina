# Source-only implementation decisions before chlorophyll response analysis

2026-11-20. The temporal gate passed. No chlorophyll–Y model has been fitted.

- Frozen product OC-CCI v6.0 is reachable via PML and the NOAA NEFSC ERDDAP mirror `occci_v6_daily_4km`; use the latter for native daily NetCDF subsets. Freeze returned metadata and hashes. No version change.
- Query native ~4 km grid cells in bounding rectangles, then apply geodesic 100 km membership and latitude cell-area weights. Rectangles do not define biological exposure. Handle dateline crossings explicitly.
- Initial pilot choice (superseded before final support or C–Y fitting): DEEP-AA 2004-06-01 valid pixels. Independent review found its finite/non--999 mask varies between dates and is not a verified static coastline. The initial one-season pilot is not used for eligibility.
- Corrected fixed denominator: NOAA ETOPO1 **ice-sheet surface**, native 1 arcminute; nearest cell to each OC-CCI pixel centre, elevation <0 m. This static marine surface excludes land/ice-shelf surface, retains seasonal sea-ice-covered ocean, and does not shrink with cloud coverage. Source endpoint, metadata and SHA256 are archived. Static historical topography cannot represent evolving ice-shelf fronts or subpixel coastlines; that limitation remains. This is a source-support correction, not outcome-selected tuning.
- OC-CCI valid positive chlor_a values use the product's missing-value/valid-range metadata; retrieve log10 RMS uncertainty alongside chlorophyll. Record coverage, valid days, half-month support, maximum missing runs and retrieval failures. Failed downloads are not ecological missingness and must be resolved or reported separately.
- The frozen support threshold (20% marine area/day; >=5 days/month with both halves observed; all four months) is unchanged. The stage is about summer pathway consistency, not a temporally ordered causal mediator.
- Retrieval optimization, before C–Y fitting: request common native region/month rectangles and apply each site's exact circle locally. Screen months in chronological order (November, December, January, February). A season that fails any month cannot meet the frozen four-month gate and needs no remaining-month download. If the remaining candidate set already has fewer than 30 sites, 6 regions or 4 seasons, this is an upper bound proving the overall support gate cannot pass; stop retrieval and label remaining rows unresolved, not confirmed eligible. Unretrieved months remain missing, never zero. Download failures are not monthly-support failures. This changes transfer volume, not eligibility or the estimand.
