2026-10-29, prior to opening original pair-level count magnitudes for *this new 381-row* climate comparison. Original counts were already exposed in older separate MAPPPD work: **explicitly post-exploration**, not a preregistered confirmation, and not a claim about anthropogenic warming.

Source roster is IMMUTABLE: verified MAPPPD5 original 771 pairs on 95 source site IDs, same published citation/vantage, ID and consecutive season, SHA256 `dfb72e533...`, source run 40867618437; paired 40-site ERA5 (1991–2020) support was independently frozen and verified **381 source pairs, 34 original site IDs, 6 source regions, 26 ERA5 grids; ADPE 294, CHPE 29, GEPE 58** via run 40867971771. Do not add pairs after viewing growth. Pin all original source SHA before retrieving 5,487 original records from MAPPPD v5.0 API. Original counts must be stage `nests`, exactly the 2 nonduplicate source observation IDs already printed in the pre-response cohort, genuine nonnegative published values. Treat zero as a numeric count where available, **never absent record as zero**.

Outcome `log1p(nests_end)-log1p(nests_start)` in the two original breeding-season start-year labels y and y+1. This is NOT a within-season reproductive-success measure, true island-wide abundance, or extinction. Exposure x is `ERA5 September monthly mean °C at source source_id, year y+1 minus year y`; a secondary diagnostic uses equal-month-weight Aug–Nov climate change. Both years' climate monthly data must already pass verified full-data/source-coordinate join. No re-fetch/tuning, nearest replacement, changing monthly definitions or selecting an outcome direction.

For the main source descriptive fit, calculate two fixed-effects designs on the EXACT same sample: species×site source ID intercepts, then source species×site + common next breeding-season start calendar-year dummies. Analytical method: residualize x and y against dummy design, slope `Σx_resid*y_resid / Σx_resid²`. Report unit `Δlog(1+nests) / +1°C annual temperature difference`. Separately report exploratory slopes for ADPE/CHPE/GEPE using same controls, ONLY if each has >=20 comparable source pairs, >=5 distinct source site IDs, >=6 distinct late years and enough residual x variation; otherwise `not identifiable`, no post-hoc relaxation. No p-values, power claims, or calibrated confidence intervals; report number of original siteIDs, publisher regions, temperature gridIds, calendar years and leave-one-grid-out range **as a sensitivity**, not CI. Local original site fixed effects prevent broad geography differences but do not eliminate observation bias or solve spatial/time dependence.

Crucial: the API has only a **breeding-season year**, not the date/method reliability of every actual field census. September y and y+1 measurements are **contemporaneous seasonal environmental indicators**, and may include dates *after* some counts; no temporal causal interpretation. Same-grid sites share reanalysis, source field counts may have overlapping publisher lineage and nonindependence. The original frozen 40-site roster was constructed for Adélie, not an unbiased multi-species global sample. **Do not interpret species-specific differences as evolutionarily or ecologically confirmed responses** without external chronological and spatial validation.

The prior 216 post-exploration phenology p-values are a different family and retain their original multiplicity correction; no use of a restricted 381 sample to "rescue" them. Frozen paper1 PR #189 and physical-island Paper2 PR #199 untouched.
