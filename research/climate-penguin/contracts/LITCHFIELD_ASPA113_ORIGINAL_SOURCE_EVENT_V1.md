# Litchfield (ASPA 113) original field-count reconciliation and climate support

**Date:** 2026-10-29. **Purpose:** reconstruct original annual observed breeding-pair/zero history without silently assigning unpublished survey months; join with the already acquired independent ERA5 reanalysis *for context*, and diagnose whether a colony-loss/greening mechanism is testable.

**Original first-party source:** 2014 Antarctic Treaty Measure 1, ASPA 113 Litchfield Island management plan, Table 1 on printed pp. 5–6 (zero-based PDF pages 5 and 6), https://www.env.go.jp/nature/nankyoku/kankyohogo/database/jyouyaku/aspa/aspa_pdf_en/113.pdf. The first-party published table contains seasonal breeding-pair counts for 1991–92 through 2012–13, including **2006–07 four breeding pairs** and **explicit zeros in six consecutive seasons 2007–08 through 2012–13**. The tabulated title ("1971–2009") is outdated relative to its actual 2012–13 entries. Both the PDF count-type note and its source-note numbers are retained. **N1 is not a calendar-month code**: N = nest, 1 = reported counting-accuracy class; note 2's "December counts" refers only to the Parmelee subset when multiple observations exist. None of the specific 1991–2012 rows is assigned a census month/day because the table does not report one.

**Source comparison:** compare all original table seasonal values against `outputs/comparison_audit/mapppd_unambiguous_site_seasons.csv`. The mapppdr source snapshot has 17 matching LITC source seasons within 1991–2012. It does not include 2006–07's positive count nor 2009–10 through 2012–13's explicit zeros. These five events are *newly recovered from the underlying primary table relative to this fixed MAPPPD snapshot*, not new independent biological measurements: MAPPPD entries may derive from the same W.R. Fraser source. The earlier MAPPPD-only zero-spell artifact had last-positive 2005 and 2007 first zero, an apparent 2-year gap. The source reconciled timeline now has 2006 positive count 4 followed by 2007 zero, but **source annual count coverage is not equal to identical monitoring effort, and the zero is an observation of recorded breeding pairs, not proof no birds ever visited**. Do not silently overwrite source data.

**Climate:** LITC matches a frozen MAPPPD macro_40 coordinate (-64.7708,-64.0919), so the independent 1991–2020 full 40-site Open-Meteo ERA5 reanalysis artifact from GitHub run 40856645581 can give annual September, August–November and annual air-temperature context. Its 0.25° ERA5 cell is not the physical island, soil temperature, true ice-free rock area or a local weather station. Source count months remain unspecified, so no time-before-census climate-effect regression is authorized. Original 1991–2010 monthly coastal sea-ice exposure is not verified complete. Do not substitute future September ice or infer local melt from temperature.

**Land/vegetation:** independent source says physical Litchfield Island area ~0.34 km², but no longitudinal accessible nesting substrate is measured. The existing Plantarctica mapped-vegetation feature matches by *point buffer* only and includes 27 mapped vegetation and 59 lichen map features within 500m; that is not 27 plots, a botanical inventory, an island polygon, or evidence of annual vegetation increase. The 2014 management plan describes extensive vegetation already present, and fur seal/elephant seal trampling, damage, and reported local recovery associated with fur seal declines. Thus an exclusive "penguin abandonment => faster greening" mechanism lacks an observed land-cover time series and control for seal history, snowfall, substrate, and different survey efforts. A published qualitative account cannot be transformed into a new original vegetation outcome.
