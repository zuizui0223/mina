# 気候履歴効果（11〜20年）の固定検証 — 実行結果（2026-11-08）

**結論：11〜20年前の海氷が現在のアデリーペンギンの年次巣数変化を予測する、という強い仮説は支持されなかった。** ただし、過去10年より11〜20年前の海氷が有利な場面もあり、「ラグが全くない」「海氷が生態的に無関係」だと解釈しない。

## 海氷の品質・比較可能性

EUMETSATの同一OSI-450-a1 v3.1の公式月次製品を1979〜1990年に用い、既存の同製品の日次抽出から計算した1991〜2020年の月次系列につないだ。0〜100 km、同じ40地点、海洋格子判定と年内8〜11月の日数重み付けを維持。

- 新しく抽出した **1,920地点月 / 40地点 / 1979〜1990年** で、必要な月の未支持・欠測は **0**。
- 1991年8月、2001年9月、2020年11月の3か月×40地点＝**120対**で、月次原本と既存日次ベースの海氷を比較。
- 絶対差の中央値 **0.08068 pp**、90パーセンタイル **0.34073 pp**、平均符号差 **+0.05505 pp**、最大絶対差 **1.16521 pp**。事前の source bridge gate（90対以上/30地点以上、中央値≤3pp、90%点≤10pp、バイアス≤3pp）を通過。
- 1987年7月以前はSMMR衛星の実測が原則48時間間隔。月次の公式集計を採用し、365日すべての観測があると偽らない。衛星/海岸線誤差は残り、三か月の照合が完全同等性を証明するわけではない。

- 2006〜2018年の**時間順**ホールドアウト：**111区間 / 17地点 / 4地域 / 13年**。各年の学習にはその年より前に終了した年次変化のみ。未知地点は当該年の採点に含めない。

## 生態学的判定

固定した成功条件「MlegacyがMrecent、Mbase、M0すべてに区間/年/地点集計で勝ち、地域除外でも維持し、差の区間が正」を満たさない。分類は **WEAK_OR_INCONCLUSIVE**（近年窓には一部勝つが基準モデルには勝たない）。

この結果は「現在の分布が過去の気候を映す」との命題の証拠ではなく、「長距離を泳げるのに繁殖地から移動しない」との機構の検証でもない。正数→正数の巣数計数から死亡、移出、加入、繁殖休止を分離できず、局所絶滅や植民、分布占有の移動を推定できない。

一方、以前の肯定結果は維持する：真正共存6地点のアデリー減少/ジェンツー増加、Palmer/Signyの実効繁殖空間縮小、Signy食性の探索的海氷関係。長期の地点間海氷相関（39地点 r=+0.622）が時系列予測に移植できないという**地理対時間の転写失敗**は示されているが、それがphilopatryによるものとは証明できない。

**論文化の扱い：** 単独の「気候負債実証」主張は採用せず、温暖化統合論文の時間・空間転写の検証に組み入れる。今後データから遅れ年を探して最良モデルを選び直さない。未来2050/2100年の生物個体数予報へ転写しない。
