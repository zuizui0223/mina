# Original nearshore SIC vs same-block penguin nest contrast: targeted diagnostic 2026-11-11

This is a **post-discovery** diagnostic after original 100-year trend ranking and the 25→9→2 common-survey-year check, NOT a prospective test or independent holdout. Limit the scope to the existing one bright/dark ecological question.

## Existing immutable source and mandatory provenance
- The previous original 595-site geographical census, method-fixed 2,456 nest records, and 1991–2020 valid annual 25-km 100-km coastal original EUMETSAT OSI SAF v3.1 SIC from Aug-Nov. Inherited source runs: original 595x30x4 monthly extraction #42612067836, original 100 long trends #42613076334, original 100-site candidates #42916058266, and common-year audit source #42919208344.
- Input original 100 site×species 1991–2020 fixed-count-method long-term colony trends and original same-year 100-site peer classification. No extrapolation to entire 595 sites.
- For **all** unordered two-distinct-original-colony pairs of the same penguin species in the same original source region AND same original EPSG3031 fixed 250-km block, compute actual common surveyed nest years, require >=5 real common years spanning >=10 years. This identifies which close spatial comparisons are feasible without picking only the Cape Royds vs Cape Crozier pair.
- For each supported pair, recalculate each site's original log1p nest-count time slope on EXACTLY the same actual counted years; use difference in original log1p nest slope per decade, and signed direction.
- Load original source-supported 595×30×4 monthly ice fields; every same site-year must contain Aug,Sep,Oct,Nov original monthly source means marked OK. For each paired actual census year, calculate each site's Aug-Nov mean SIC (0–100 pp), and report yearly pairwise mean of signed/absolute SIC difference, each site's SIC slope in pp per decade, and slope difference **on the same years**.
- Keep only pairs with all selected matched count years climate-valid; otherwise record exact source missingness and no physical comparison (no SIC=0). All source files and 595-site geometry pinned to previous source receipts.
- Report haversine great-circle distance (km) between original site coordinates; report 100-km local subset as a descriptive original-buffer-scale context, not biological foraging range.
- Explicit original local case: the two selected strong geographically peer-supported sites Adélie Cape Crozier West (CRZW; source-relative bright) and Cape Royds (ROYD; source-relative dark) — same Ross Island locality **verify original geometry and block identity**, never assume. If they share a fixed 250km block and meet temporal source support, show their direct common-year contrast and original same-year nearshore SIC comparability; else flag no paired case.
- No regression of physical sea ice against nesting residual, no new multiple-comparison lag search, no external bathymetric mechanism claims. Original 8–11 month nearshore SIC cannot resolve local breeding-time icebergs, colony access, food/prey supply or mortality. Historical literature identifies candidate mechanisms (iceberg blockage, polynya access, anthropogenic access); their existence is NOT established by this analysis.
- Do not call a selected top candidate significant unless you have independent ecological replication. Geographic 250km block matching is a shared-source diagnostic, not an experimental randomized treatment.
- Outputs: one row per feasible same-block pair with exact common years and SIC support, broad source-denominator summary, source panel for any same-block bright-vs-dark candidate, named CRZW/ROYD report if source conditions permit. If the named pair is unsupported, say so without inventing their change or a "no ice effect" inference.

## Decision boundary
This comparison can identify **whether large different observed nest-count changes occur among neighboring originally surveyed colonies despite similar or different measured local 8–11 ice**. It cannot infer true migration among colonies, reproductive fitness, local causal refuges, air temperature changes, sea-ice icebergs, winter foraging niches, or the fraction of variance attributed to climate.
