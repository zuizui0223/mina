# Original common-census-year bright/dark colony holdout sensitivity — source-defined follow-up (2026-11-11 JST)

## Why this analysis is needed

The first exploratory source-backed analysis ranked observed site×species slopes (100 long census series; 90 with valid same-species/same-region reference; 7 strict source-bright and 18 strict source-dark candidates). However, peer sites may have census **in different calendar years**. The previous leave-one-site-out same-region *slope* baseline can therefore compare a site's boom decade with a peer's bust decade. A good source observational control must compare same-year changes, not only same biological species and source regional label.

This is a follow-up **outcome-aware sensitivity test**. Do not call it independent validation of biological performance or retrospectively pre-registered evidence.

## Frozen source and matched-year estimand

- Use exact same branch and prior original outputs: 100-site×species observed regional candidate table (from successful Actions #42916058266, artifact 13809755852) and original method-consistent 2,456 nest counts and 595 site inventory pinned via original macro_panantarctic_v1/build.py. Existing eligible site×species identities and 6 comparable source region×species groups must not change; missing survey years are never zeros.
- Primary response for every one of the original 90 candidate-comparable site×species groups, whether initial residual bright, dark or neutral: For each distinct other colony in the SAME species AND SAME original reporting region, intersect the two sites' **original observed census season integers** within 1991–2020. Retain a comparator ONLY if **>=5 actual co-observed years spanning >=10 years**. Fit separate OLS slopes of log(1+observed original nests) on observed year, *both on the identical intersection years*, then take focal minus peer slope (per decade). Report n intersection years, exact endpoints, separate original fixed counting methods, same 250km source spatial-block status.
- A focal eligible for a **descriptive synchronized comparison** needs >=3 valid comparator site IDs, of which >=2 occur outside the focal's own frozen EPSG3031 250km geographic block. This limits pseudoindependence in one local area but is not statistical spatial independence. Keep focal results with zero/insufficient matched comparators as unsupported, not neutral or zero slope.
- Descriptive robust-sign gate: require source original candidate strict status (>=10 genuinely observed census years over >=20 years; prior Theil–Sen and first/last actual count year deletion both agree with the sign), synchronized peer median difference same sign as original source residual AND >=75% of valid comparator signs agree, plus >=3 valid contemporaneous peers and >=2 valid outside-block peer site IDs. Require at least **two distinct external polar 250km blocks** in a second stronger column; if unavailable mark geographic replication unsupported separately. Both gates can fail, report every candidate.
- Report each candidate's same-year first/last count zero flags, any recorded original count zero, count-year completeness (n observations and span), correlation of source observed survey-year midpoint with trend deviations as a diagnostic ONLY, and matched peer methods. **Do not** exclude source-zero years to create a favorable biological pattern; report a zero-free sensitivity separately by excluding true zero recorded years from each *matched-year pair in both sites*, still requiring >=5 actual common original seasons over >=10 years. Never call an observed zero a proved new colony or extinction without survey effort metadata.
- For a given focal, report total valid same-year peers, outside-block valid peers, number of distinct outside polar blocks, median matched-year focal-minus-peer slopes for all and zero-free subset, directional agreement fraction, and full individual pair records. No t-test/p-value, no regression-outcome tuning or covariate fishing.
- Record comparison observations from **fixed-method original source**. The real temporal range and year intersection are necessary for the ecological reading.
- A code-stability gate re-reconstructs all original OLS slopes and compares the original first PR215 result (100/100 within 1e-8).
- No original sea-ice SIC coefficient, marine 60% thresholds or external bathymetry is chosen based on outcome. Sea ice and terrain remain separate independent next-source covariates AFTER temporal source quality is tested.

## Scientific interpretation and expected outputs

This analysis can identify **which initially proposed relative bright/dark anomalies survive matched survey years**; it cannot establish biological demographic resilience, causal climatic refuges, individual migration, future warming forecasts or actual colony absence. The main output is a single machine-readable 90-candidate table with same-year matching, 25 strict candidate re-evaluations, per-pair observed-year evidence, and source/selection report. Keep negative and unsupported outcomes; do not replace the original six comparison groups by convenient new groupings.

The core ecological question remains "Why do colonies of the same species in the same Antarctic region exhibit unusually different observed nest-count trajectories?" These candidates are leads, not a finished mechanism.
